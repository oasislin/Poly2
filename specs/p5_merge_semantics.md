## 一、 算法概述与设计哲学

在概率预测系统的可靠性评估中，等宽分箱（如 20 个 5% 概率档位）常因极端尾部或偏态预测导致局部概率档样本量匮乏（$n < \min\_n$）。小样本分箱会导致 Wilson 置信区间过宽、方差过大，从而诱发伪失准误报。

为兼顾**横向概率分辨率**与**统计推断稳健性**，P5 检验引擎主轨采用**确定性贪心自适应合并算法（Greedy Adaptive Bin Merging）**：
1. 初始构建 $K = 20$ 个等宽分档 $[0.00, 0.05), [0.05, 0.10), \dots, [0.95, 1.00]$；
2. 逐轮扫描并定位最左侧样本量未达标的小桶；
3. 基于邻近桶的平均预测概率偏差 $|\Delta \bar{p}|$，贪心选择与其最近的相邻桶进行合并；
4. 更新合并桶的统计量与分箱边界，直至满足确定性终止条件。

---

## 二、 数学符号与状态定义

设当前迭代轮次 $t$ 中，分箱集合为 $\mathcal{B}^{(t)} = \{ B_0, B_1, \dots, B_{K-1} \}$，其中 $K = |\mathcal{B}^{(t)}|$：
- **分箱样本量**: $c_i = n(B_i) \in \mathbb{N}_{\ge 0}$，满足 $\sum_{i=0}^{K-1} c_i = N$（$N$ 为全域总样本量）；
- **分箱平均预测概率**: $\bar{p}_i \in [0, 1]$；
- **分箱区间范围**: $I_i = [l_i, u_i) \subseteq [0, 1]$（最右桶可为闭区间 $[l_{K-1}, 1.0]$）；
- **法定样本门限**: $\min\_n = 30$（附注 A4 指明，支持粗筛级统计推断）。

## 三、 C1 ~ C3 裁决规则的严格数学表述

在每一轮合并迭代中，算法执行以下确定性裁决流水线：

### 3.1 C1: 最左优先选择 (Leftmost Small Bin Selection)
扫描当前所有分桶，找出样本量低于门限 $c_i < \min\_n$ 的所有分桶下标集合：
$$\mathcal{I}_{\text{small}} = \{ i \in \{0, 1, \dots, K-1\} \mid c_i < \min\_n \}$$

若 $\mathcal{I}_{\text{small}} \neq \emptyset$，选择其中**最小的下标**作为本轮待处理的目标小桶：
$$i^* = \min(\mathcal{I}_{\text{small}})$$

> **设计理由**: 确定性从左向右（从低概率端向高概率端）线性扫描，杜绝多小桶共存时的随机选取或双向漂移，确保机器推导严格单调、唯一。

### 3.2 C2: 邻近距离度量与平局裁决 (Distance Minimization & Tie-Breaking)
针对目标小桶 $i^*$，计算其与相邻分桶在平均预测概率空间的绝对偏差：
- **左邻偏差**: 
  $$\Delta_L = | \bar{p}_{i^*} - \bar{p}_{i^*-1} | \quad (\text{仅当 } i^* > 0 \text{ 时有效，否则 } \Delta_L = +\infty)$$
- **右邻偏差**: 
  $$\Delta_R = | \bar{p}_{i^*} - \bar{p}_{i^*+1} | \quad (\text{仅当 } i^* < K-1 \text{ 时有效，否则 } \Delta_R = +\infty)$$

合并目标伴侣桶（Partner Bin）下标 $j^*$ 依如下规则判定：
1. **单边边界条件**:
   - 若 $i^* = 0$（最左端桶，无左邻），强制合并至右邻：$j^* = 1$；
   - 若 $i^* = K - 1$（最右端桶，无右邻），强制合并至左邻：$j^* = K - 2$；
2. **双边比较与平局规则**:
   - 若 $\Delta_L < \Delta_R - 10^{-9}$：合并至左邻，$j^* = i^* - 1$；
   - 若 $\Delta_R < \Delta_L - 10^{-9}$：合并至右邻，$j^* = i^* + 1$；
   - 若 $| \Delta_L - \Delta_R | \le 10^{-9}$（偏差绝对相等或在浮点容差 $10^{-9}$ 内）：**平局强制归左（Tie-break to left neighbor）**，即 $j^* = i^* - 1$。

### 3.3 C3: 状态转移与属性递推 (State Transition & Property Recurrence)
令要合并的两个相邻桶为 $i_{\min} = \min(i^*, j^*)$ 与 $i_{\max} = \max(i^*, j^*)$（其中必定满足 $i_{\max} = i_{\min} + 1$）：
1. **记录合并事件**:
   将本次动作记入合并操作序列：$\text{merges}.\text{append}([i_{\min}, i_{\max}])$；
2. **样本量合并**:
   $$c'_{i_{\min}} = c_{i_{\min}} + c_{i_{\max}}$$
3. **平均预测概率更新**:
   $$\bar{p}'_{i_{\min}} = \begin{cases} \dfrac{c_{i_{\min}} \bar{p}_{i_{\min}} + c_{i_{\max}} \bar{p}_{i_{\max}}}{c_{i_{\min}} + c_{i_{\max}}}, & \text{若 } c_{i_{\min}} + c_{i_{\max}} > 0 \\ \dfrac{\bar{p}_{i_{\min}} + \bar{p}_{i_{\max}}}{2}, & \text{若 } c_{i_{\min}} + c_{i_{\max}} = 0 \end{cases}$$
4. **区间合并与留痕**:
   $$I'_{i_{\min}} = [l_{i_{\min}}, u_{i_{\max}})$$
5. **结构弹出**:
   从分箱集合中移除 $B_{i_{\max}}$，后续分桶下标前移，总桶数 $K \leftarrow K - 1$。

## 四、 确定性终止条件与边界输入行为

### 4.1 确定性终止条件 (Termination Predicates)
每一轮合并前，依次评估终止准则。满足以下任一条件时，循环必须**立即且无条件终止**：
1. **全员达标终止**: $\forall i \in \{0, \dots, K-1\}, \; c_i \ge \min\_n$（即 $\mathcal{I}_{\text{small}} = \emptyset$）；
2. **单桶物理极限制**: 当前剩余桶数 $K \le 1$（无法再与任何相邻桶合并）。

> **关键纪律（预言书修订 #3 裁定根因）**:
> 一旦当前所有桶均满足 $c_i \ge \min\_n$，合并算法必须立即退出。**严禁继续对已达标桶进行跨档强行合并**（如将 $60$ 与 $40$ 的两个合规桶继续合并）。任何违反终止条件的过度合并均属非法。

### 4.2 边界输入行为 (Boundary Behaviors)
对于各类极端或退化输入，算法统一定义法定输出行为：

| 边界场景 | 前提条件 | 算法行为 | 返回格式 |
| :--- | :--- | :--- | :--- |
| **总样本量不足** | $N = \sum c_i < \min\_n$ | 不启动合并循环，不修改分箱，打标不足 | `([], False)` |
| **初始全员达标** | $\forall i, c_i \ge \min\_n$ | 循环直接判定退出，无任何合并 | `[]`（或 `([], True)`） |
| **全域退化单桶** | 初始输入仅有 1 个桶 | 无法合并，直接退出 | `[]` |
| **全零空桶输入** | $N = 0$ | 归入总样本不足场景 | `([], False)` |
| **连环合并巨桶** | 连续多桶 $c_i < \min\_n$ | 依法合成为宽区间桶（可能 $\Delta p > 0.15$），记录子段映射并打标 `WIDE-BIN` | 正常产出合并序列 |

## 五、 双路径判定准则 (Dual-Path Evaluation Protocol)

根据数据源特性与执行阶段，P5 确立两套互不污染但数理对齐的双路径准则（附注 A1）：

### 5.1 合成考题阶梯路径 (Synthetic Test Path)
- **应用场景**: S1–S5 阶梯用例离线校验、`--synthetic-suite` 自动化回归、算法确定性冒烟。
- **初始 $\bar{p}$ 设定**:
  由于合成考题仅给定样本量分布向量（如 $[50] \times 15 + [10] \times 5$），缺少微观样本预测值，故**初始平均预测概率固定绑定为 20 等宽分档的理论几何中点**：
  $$\bar{p}_i^{(0)} = 0.05 \cdot i + 0.025 \quad (i = 0, 1, \dots, 19)$$
- **递推计算**:
  合并迭代中严格沿用 C3 的加权递推公式更新 $\bar{p}'$；
- **裁决机制**:
  合成路径在遇到 $|\Delta_L - \Delta_R| \le 10^{-9}$ 时，强制使用 C2 归左规则。

### 5.2 真实数据流路径 (Real Data Stream Path)
- **应用场景**: GHCN-Daily 实测真值与 GEFS 概率预报回测对账、生产流水线实时监控。
- **初始 $\bar{p}$ 设定**:
  每个初始分桶 $B_i$ 的平均预测概率**严格基于落入该分桶的所有样本预测概率 $p_j$ 的真实算术均值**：
  $$\bar{p}_i^{(0)} = \frac{1}{c_i} \sum_{j \in B_i} p_j \quad (\text{若 } c_i > 0)$$
  （若 $c_i = 0$，则采用理论中点 $0.05 \cdot i + 0.025$ 占位）；
- **全局一致性保证**:
  由于样本加权平均具有可加性：
  $$\frac{c_1 \cdot \left(\frac{1}{c_1} \sum_{j \in B_1} p_j\right) + c_2 \cdot \left(\frac{1}{c_2} \sum_{j \in B_2} p_j\right)}{c_1 + c_2} = \frac{1}{c_1 + c_2} \sum_{j \in B_1 \cup B_2} p_j$$
  合并桶的加权 $\bar{p}'$ 在真实数据流下与直接在大桶中计算样本经验均值在数学上严格等价，零数值漂移。
