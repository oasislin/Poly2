# 子任务执行单：Polymarket 结算站点身份审计与闭环评分（M0'）

## 0. 背景与核心命题
数据源已决策全面拥抱 NWS 生态，站点集合由固定 {ZSPD, KDEN}
改为可枚举、可筛选。本执行单回答三个问题：
1. Polymarket 各温度市场的结算站号到底是什么（传闻 KBKF 待裁决）？
2. 哪些站点满足"闭环五要素"？
3. 首发站与第二站选谁？
