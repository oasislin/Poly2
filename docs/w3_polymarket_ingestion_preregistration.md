## 一、 盘口拉取方式与市场范围

### 1.1 CLOB API 只读通道契约
1. **只读公开通道（Public Read-Only Endpoints）**：
   - 采用 Polymarket CLOB HTTP REST / WebSocket 公共行情端点；
   - 严格限定请求范围为只读公共行情：市场元数据查询（`/markets`）、订单簿快照（`/book`）与公共价格行情；
   - 绝对禁止调用任何需要签名权限的私有端点（如 `/order`、`/cancel`、`/trades` 私有历史）；
2. **零私钥与零认证绝缘（Zero Authentication / Zero Signer）**：
   - 盘口采集模块严格不加载、不读取、不解析任何生产私钥或 API 交易凭证（API Secret/Passphrase）；
   - 运行时上下文环境变量必须剥离任何钱包私钥注入；
3. **频率限制与反压管理（Rate Limiting & Backoff）**：
   - 严格遵守 Polymarket 公共 API 速率限制配额；
   - 遇 HTTP 429 速率限制或网络抖动时，采用指数退避迟滞策略，坚决禁止激进轮询。

### 1.2 市场订阅范围 (C-1)
- **订阅范围 (C-1)**：仅 Polymarket 当前活跃的温度类合约（Active Daily Temperature Markets），逐日清单落盘。

## 二、 采样架构规范（时间不敏感 · 定时快照批处理）

依据工单 `P7-W3-SPEC-APPROVE-001` 审定之 A 组判据：

| 编号 | 判据条目 | 定稿法定值 | 详细执行规则 |
| :---: | :--- | :--- | :--- |
| **A-1** | **基准层频次** | **每 60 分钟 1 次全量快照** | 针对全部订阅市场进行定时批处理快照抓取。 |
| **A-2** | **结算探测层** | **T-12h 起，每 15 分钟 1 次** | 仅针对临近结算的特定市场提高采样频次，捕获结算前盘口与物理极值互动。 |
| **A-3** | **T-0 定义** | **$\equiv$ 合约官方结算时间戳** | 严格采用 Polymarket 市场规格所载之官方结算时间戳（Settlement Time），禁止以台站当地日终自行推算。 |
| **A-4** | **PROB_STATIC 条款** | **我方概率跨快照不变照常全量落盘** | 我方概率跨快照不变的段位照常全量落盘，显式标记 `PROB_STATIC`，禁止去重丢弃（作为指标 A 对照基线）。 |
| **A-5** | **快照自洽原则** | **独立截面，禁止跨时刻实时性假设** | 每张快照为独立截面，分析时以快照时刻盘口与同期气象数据配对，禁止跨时刻实时性假设；**无 STALE 挂起机制**。 |

## 三、 盘口到对价映射与信号判定规范

依据工单 `P7-W3-SPEC-APPROVE-001` 审定之 B 组判据：

### 3.1 盘口对价映射与深度过滤
| 编号 | 判据条目 | 定稿法定值 | 详细执行规则 |
| :---: | :--- | :--- | :--- |
| **B-1** | **对价取法** | **买入侧用最优 ask、卖出侧用最优 bid** | 采用保守侧成交价；市场中间价（Mid Price）仅用于监控与展示，不用于 EV 计算。 |
| **B-2** | **无报价处理** | **记 `NO_QUOTE`，不评估** | 当 ask 或 bid 缺失时，该档位显式标记 `NO_QUOTE`，不进行后续 EV 评估。 |
| **B-5** | **最小深度** | **最优档可成交量 $\ge 10$ 份** | 最优档可成交量 $\ge 10$ 份方可生成交易信号；深度不足 10 份拦截信号，标记 `REJECTED_INSUFFICIENT_DEPTH`。 |

### 3.2 真实 EV 定价与信号判定
| 编号 | 判据条目 | 定稿法定值 | 详细执行规则 |
| :---: | :--- | :--- | :--- |
| **B-3** | **正 EV 门槛** | **$\text{edge} = \text{我方概率} - \text{买入价} \ge 5$ 个百分点** | 仅当 $\text{edge} \ge 0.05$ 时，方打上 **`POSITIVE_EV_SIGNAL`** 标签。 |
| **B-4** | **全量评估落盘** | **每一次档位评估完整落盘** | 完整落盘各档位之：我方概率、ask、bid、中间价、edge、深度，不论是否跨过 EV 门槛。 |
| **B-6** | **分歧监控** | **偏离 $> 15$ 个百分点打标** | 当我方概率与市场中间价绝对偏离 $|\text{我方概率} - \text{中间价}| > 0.15$ 时，打标 **`MODEL_MARKET_DIVERGENCE`**；只记录入法医日志，不阻断交易。 |

### 3.3 继承之资产治理约束（沿用 W2-A / Rev.1.1 冻结项）
1. **KMIA_12h 挂旗资产**：强制继承 `COMPLETED_ECE_FLAGGED` 治理标签，头寸额度硬折剪 50%；
2. **FAILSAFE 粗粒度资产降级**：若发生路由回退，强制执行 `FAILSAFE_DEGRADED_READONLY`，可交易信号严格置 0；
3. **死档（$p_k = 0.0$）绝对拒绝**：严禁向死档发出任何执行信号。

## 四、 离线拟合条款（观测期后执行）

依据工单 `P7-W3-SPEC-APPROVE-001` 审定之 D 组判据，于观测期结束后执行离线拟合与参数校准：

| 编号 | 判据条目 | 定稿法定值与执行方案 |
| :---: | :--- | :--- |
| **D-1** | **门槛扫描** | 基于全量评估底账，对 $2\% \sim 15\%$ 门槛进行离线重放，产出“频次-期望收益曲线”，供 W4 实盘前置定稿参考。 |
| **D-2** | **指标 A（领先性）** | 在结算探测窗内，若我方概率发生跳变 $> 3$ 个百分点，检验市场中间价是否在随后 $1 \sim 3$ 张快照内同向跟随：<br>• 跟随显著 $\rightarrow$ 支持保留结算探测层；<br>• 市场先行 $\rightarrow$ 支持砍掉探测层。 |
| **D-3** | **指标 B（校准兑现）** | 在结算探测窗内，对过门槛信号分别按“我方概率 vs 市场隐含概率”对照实际结算命中率：<br>• 我方显著优 $\rightarrow$ 判定 EV 为真实优势；<br>• 无差异或更差 $\rightarrow$ 提高门槛或砍掉探测层。 |

## 七、 红线与治理纪律声明（E 系列红线体系）

1. **C5 安全红线 (E-1)**：W3 阶段外部资金（Free USDC / 链上资产）变动严格为 **`$0.00`**；生产私钥、助记词或签名凭证**绝对禁止加载进入代码或内存**；系统仅使用公开只读行情 API，**任何形态的下单接口调用、签名生成或发送订单尝试即判定为 ERROR 级严重违令**，直接终止会话。
2. **数据性质法定标注条款 (E-2)**：所有落盘与报告工件必须带有不可篡改的 `DATA_PROVENANCE` 标签（`POLYMARKET_LIVE_CLOB` vs `SYNTHETIC_INJECTED_REPLAY`），禁止任何含混表述。
3. **预注册纪律 (E-3)**：规格书与 Annex 定稿后，观测期判据不得中途修改；若执行中发现判据不适用，停止、记录、呈报委员会，不得临场改数。
4. **证据溯源真实性红线 (E-4)**：任何进入 `data/` 或 `evidence/` 的数据，其输入来源必须可追溯至真实管线或显式标注的占位物；严禁以占位输入产出标注为模型实况的下游记录。违者按 ERROR 级违令处理。
5. **自创设计决策零容忍红线 (E-5)**：位次 4/4 及以后，实现中的任何自创设计决策（包含未明载于规格书的数学算法、数据归一化、插值假定、常数阈值与工程分支）未经 `DESIGN-CLARIFY` 或 Annex 获批，一律按 ERROR 级违令处理。所有既有未载明算法已全量收敛至 Annex A 提交委员会逐项裁定。
