### 3.2 判决书 P7-ALGO-VERDICT（M-1~M-8 判词 = 立法输入，必须通读并逐条落实）
关键判词摘要（完整以 `docs/audit/P7-ALGO-VERDICT.md` 为准）：
- **M-1 改造移植**：v1 稳健凯利 Minimax 改造移植，θ/η 不继承，标定挂 F-2 锁；
- **M-2 已裁**：追认 `q = p·[1+base·(1−p)]`，base=0.0125（待办：base 值与 Maker 返佣 0.20 对外核实一次后闭环）；
- **M-3 保留**：C-2 Dutch Book 跨档无风险反向锁利 + C_loc 预算豁免（已解锁）；
- **M-4 废弃**：C-1 胜率向市场价收缩 Shrinkage（已解锁=废弃）；
- **M-5 框架复用**：C-3 两步标定法反事实模拟参数寻优（已解锁）；
- **M-6 确认废弃**：附 ADR-0013 截断层场景覆盖性验证条件；
- **M-7 整体废弃**：Sigmoid 时间衰减（由 EMOS σ(L) 承担）、φ=1.3（由 ADR-0011 管辖）；
- **M-8 照准**：归档声明不继承。
- **F-2 优先律（硬前置）**：概率层 ECE/CRPSS 门禁未绿灯前，**凯利标定与 sizing 调优不得开工**。规格书结构可先写，标定与上线挂锁。

## 五、角色分工与协作流程

| 角色 | 职责 |
| :--- | :--- |
| **本对话 Agent（量化投资专家 + 算法专家）** | 主导算法框架：算法目的提取、数学建模、Kelly 公式形态、sizing 方案、执行定价、门禁设计 |
| **开发端 Agent（另一 conversation）** | 具体落档细化：代码级可行性核对、数据结构、参数定义、接口设计、落盘文档细化 |
| **用户** | 最终裁决：术语、判词、公式、门禁、成稿批准 |

**Debate 流程**：
1. 本对话 Agent 出**算法框架初稿**（目的、公式、门禁、依赖）；
2. 开发端 Agent 从落档/工程可行性角度**质询与细化**（多轮）；
3. 双方对每个设计决策点**达成一致**（含分歧记录与裁决项）；
4. 分歧无法达成时，**列为待裁决项交用户**；
5. 全部一致后**最终成稿**，交用户确认。
