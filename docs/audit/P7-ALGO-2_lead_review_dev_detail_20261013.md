## 二、必须修正项（P0，影响正确性或完整性）

### P0-1 【数学承诺偏差】SLSQP 目标函数加入凸二次罚函数，破坏规格书 §3.3 凹性证明
- **位置**：§4.3 `objective()` 的 `penalty = 1e6 * Σ(eps−wealth[bad])²`
- **问题**：规格书 §3.3 引理 1~3 证明目标为凹函数（ln(线性) 非负加权和），SLSQP 全局收敛基于"凹最大化于凸集"。二次罚项是**凸函数**，凹目标 + 凸罚 = **非凹非凸**，全局收敛保证不再成立。
- **影响**：若迭代触及 W_i≤eps 区域，目标偏离凹性，可能收敛到局部最优；规格书"全局最优"承诺被静默降级。
- **修正建议（三选一，须明确声明）**：
  a. **域内保持凹**：声明罚项仅在越界区域（bad_mask）激活、可行域内目标仍凹，从可行起点（f0 小值）出发 SLSQP 不触碰越界区则局部=全局——需在文档显式论证并测试；
  b. **硬约束替代**：把 W_i(f) > eps 作为不等式约束交给 SLSQP（cons 列表），保持目标纯凹；
  c. **明确降级**：接受罚函数局部最优，删除"全局收敛"表述，改为"近似求解 + Fail-Closed 防御"（需用户知晓此与规格书 §3.3 的差异）。

### P0-2 【防御缺口】贪心投影未处理 Σp_U < 1 的区间不可行
- **位置**：§4.2 `project_worst_case_probabilities`
- **问题**：规格书 §4.2 可行性条件为 Σp_L ≤ 1 ≤ Σp_U。开发端只处理 Σp_L ≥ 1（归一化），**未处理 Σp_U < 1**（上限和不足）：此时贪心耗尽所有档仍 Σp < 1，末尾"精细归一化"会把概率放大**违反 p ≤ p_U 上界**，产生越界分布。
- **修正**：增加 Σp_U < 1 退化分支（WARNING 日志 + 归一化输出或 fail-closed），与 Σp_L ≥ 1 对称。

### P0-3 【逻辑缺口】evaluate_all_gates 的 ALL_SYSTEMS_PASS 遗漏 G1/G2
- **位置**：§五 `evaluate_all_gates`
- **问题**：`ALL_SYSTEMS_PASS` 仅含 G6/G5/G7；G1（单市场 10%）与 G2（全局 70%）布尔值虽单独给出，但未纳入总放行判定。若调用方以 ALL_SYSTEMS_PASS 做总放行，**超限订单可能被放行**。
- **修正**：ALL_SYSTEMS_PASS 纳入 G1/G2 通过判定；或明确"G1 超限按比例缩水、G2 超限拒绝"发生在放行判定之前的前置流程（规格书 G1 为缩水语义、G2 为硬顶，需显式落位）。

### P0-4 【模块遗漏】M-G 横切组件与仿真层未落位
- **问题 A（M-G 不完整）**：`risk/` 下仅有 central_arbiter；规格书 M-G 包含 **Incident 契约/事件总线（incident_protocol）** 与 **本地硬阀哨兵（emergency_control，EMERGENCY_STOP_* 文件探测）**——均未规划落位。ADR-0014 的零发射定理依赖本地硬阀；审计词表含 `HARD_VALVE_ZERO_EMISSION_BLOCK` 但无对应模块。
- **问题 B（仿真层缺失——M8 标定数据源断链）**：verification/ 仅 settlement_simulator + financial_calibrator；规格书 §9 与 M-5 判词要求**纸面盘自产数据**（paper_engine 链路 + 合成做市对手盘 market_maker + 回测/2019 盲测年）作为两步标定 Step 1 的数据源。F-2 解锁后若无纸面盘链路，标定无数据可标。**须补充 simulation/ 规划**（paper_engine、backtest_engine、market_maker 合成盘口）。
- **修正**：在模块树补充 `risk/incident_protocol.py`、`risk/emergency_control.py`；补充 `simulation/`（或 verification 下）纸面盘/回测/合成做市规划。
