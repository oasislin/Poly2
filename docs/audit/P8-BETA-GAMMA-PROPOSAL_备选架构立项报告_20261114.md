### 1.2 失败机理：通道错位与结构缺陷双分量分解（`2019-SEALED-001` 修订版）

结合终跑与 `2019-SEALED-001` 完整的 `{5min_LST, OfficialMETAR_LST} × {GHCN_LST, OfficialMETAR_DST}` **2×2 全空间反事实结果**（详见 [`FULL-DOSSIER §三`](P8-INSPECTION-C-FULL-DOSSIER_20261114.md#三-封跑反事实与判决稳健性2019-sealed-001-终闭合)），方案 $\alpha$ 的检验 C 失败原因必须严格拆解为**性质完全不同的双分量**，禁止继续混为一谈：

1. **信息价值与结构可行性前提已双源确证**：
   无论采用 `GHCN(LST)`（`CRPS` `2.505005 -> 1.294325`, `-48.33%`）抑或 `OfficialMETAR(DST)`（`CRPS` `2.545171 -> 1.432047 [T1]` / `1.193529 [T2]`, `-43.7% ~ -53.1%`），均在 `16/16` 全分层交付了巨幅连续预报价值。失败根因不在日内观测条件化方向本身。
2. **双分量分解式（`G3c` 通道错位可消 vs `G3a / G3b` 纯结构失败四配置一致）**：
   $$\text{总观测失准（检验 C 四配置）} \;=\; \underbrace{\text{分量一：通道错位分量（仅影响跨源 } G3c\text{，可由流选型消除）}}_{\text{终跑 } 0.0306 \;/\; \text{变体2 } 0.0344 \;/\; T1\ 0.0324 \;\longrightarrow\; T2\ 0.008301\ (\text{过})} \;+\; \underbrace{\text{分量二：单高斯结构耦合分量（}G3a / G3b\text{ 四配置 100\% 败）}}_{\text{终跑 } +5.30/+8.08\sigma \;\cdot\; \text{变体2 } +8.68/+11.89\sigma \;\cdot\; T1\ +8.94/+13.55\sigma \;\cdot\; T2\ +11.53/+14.65\sigma}$$
   - **分量一｜`G3c`（池化 11 档 `ECE`）主受“观测流 × 结算真值通道错位”支配（可消除）**：
     只要观测流与结算真值存在跨源或跨日界混配（`5min_LST × GHCN_LST = 0.030586`、`METAR_LST × GHCN_LST = 0.034378`、`5min_LST × METAR_DST = 0.032407`），`ECE_bridge(inw)` 一律滞留在 `0.031–0.034` 地板之上（较先验基线 `0.0029–0.0036` 高出一个量级）；**而当且仅当切换为同源配置 `T2`（`OfficialMETAR_LST × OfficialMETAR_DST`）时，全池 `ECE_bridge(inw)` 立即骤降至 `0.008301 <= 0.020`（`w20 = 0.008521`）通过 `G3c`**。该实证推翻了“全池 `0.031+` 的 `ECE` 地板全部由高斯桥本身产生”的旧认识，确认**生产观测流与结算源同源对齐即可消除通道错位分量**。
   - **分量二｜`G3a / G3b`（边界原子校准）属于“单高斯点-尾耦合刚性”纯结构失败（四配置一致恶化）**：
     在方案 $\alpha$ 构造 $G_t(d) = \Phi((d - \mu_R)/\sigma_{\text{rem}})$ 下，给定 $\sigma_{\text{rem}}(t) = \max(\sigma_0\sqrt{\eta_s(t)}, 0.9^\circ\text{F})$，单一自由函数 $\mu_R(t, m, X_t)$ 被迫同时决定离散边界锁顶原子 $p_{\text{lock}} = \Phi(-\mu_R / \sigma_{\text{rem}})$ 与正剩余连续上尾分布 $R_t^+ \mid R_t > 0$。当加入连续 `CRPS` 与切片期望约束以守住 `G2a` 后，**无论真值取 `GHCN` 还是 `METAR`、无论观测取 `5min` 还是同源 `METAR`**，午后 `G3a` 与早段 `G3b` 原子出界 **四配置 100% 全线失败**，且在消除了通道错位的同源 `T2` 上反而进一步裸露放大为 `G3a 60/312 (z=+11.53, B2 wResid=+0.0275)` 与 `G3b 59/224 (z=+14.65)`（全池 `ECE` 通过仅因 11 档正负偏差在档间相互抵消，而单点/半小时原子错配依然剧烈）。
3. **误差预算认知修正（关联审查记录 §十一、§十二）**：
   跨源主判宇宙中约 `0.027` 的 `ΔECE` 实由**跨源通道错位主项**与桥结构失真共同构成；仅靠换源（从 `5min` 切换同源 `METAR`）虽可消解 `G3c` 通道项至 `0.0083`，却会令 `G3a / G3b` 原子结构缺陷更显著暴露（`z > +11`），故必须由 **`β / γ` 分布族架构重构（解耦点质量与正尾部）+ 生产观测流同源评估**双线治本。

## 二、 候选架构枚举（机制对症 × 效果待验）

以下三类候选架构均严格满足两项前置工程不变量：① 消费冻结的三实况输入签名 `(extreme_m, instant_x_t, t_local)` 与 `(mu_0, sigma_0, family, shape_params)`；② 向阶段 4 输出合法左极限 CDF $G_t(d)$（或直接输出完备归一化 11 档概率向量，维持 $\sum p_k = 1.000000$ 与已越界死档 $p_k \equiv 0$）。

### 2.1 候选一｜Hurdle 两阶段条件剩余分布（`方案 β-1`）

- **数学形式**：
  将残余温度增量 $R_t = \max(0, T_{\text{fin}} - m)$ 显式分解为“零点质量门（Hurdle）”与“严格正剩余连续分布（Severity）”双子模型：
  $$G_t(d \mid \mathcal{F}_t) = \begin{cases} 0, & d < 0 \\ p_{\text{lock}}(\mathbf{z}_t) + \big(1 - p_{\text{lock}}(\mathbf{z}_t)\big) \, F_+\!\left(d \;\middle|\; \mathbf{z}_t, \sigma_{\text{rem}}(t)\right), & d \ge 0 \end{cases}$$
  其中：
  1. $p_{\text{lock}}(\mathbf{z}_t) = \mathbb{P}(R_t \le 0 \mid \mathcal{F}_t) \in (0, 1)$ 由保序可微广义相加模型（如样条 Logistic / 分层正则化逻辑回归）或带单调约束之校准分类器按 `(station, season)` 拟合；
  2. $F_+(d \mid \mathbf{z}_t, \sigma_{\text{rem}}(t))$ 仅在历史“确实继续升温（$R_t > 0$）”子样本上拟合连续正支撑域分布（候选核：缩放截断正态、Log-Normal 或 Gamma / Burr XII，尺度受 $\sigma_{\text{rem}}(t) = \max(\sigma_0\sqrt{\eta_s(t)}, 0.9^\circ\text{F})$ 约束）。
- **机制对症（结构性归因——直接观测证据升格）**：
  - **直接观测证据（由 `T2` 反事实升格）**：在同源无通道错位的 `T2`（`OfficialMETAR_LST × OfficialMETAR_DST`）实测中，桥已经同时达到 **`ECE_bridge(inw) = 0.008301`（过门禁）与 `CRPS_bridge = 1.193529°F`（`-53.106%`）**，唯独锁顶边界原子（`G3a = 60/312`, `G3b = 59/224`）在全部四配置下持续崩溃。这直接观测证明：**单高斯桥真正失配的部位正是离散锁顶原子概率与条件正增幅分布的耦合锁死**；Hurdle 架构通过拆分独立的 $p_{\text{lock}}$ 与 $F_+$ 恰好直接切中该实证病灶，对症证据由先前的间接推断升格为直接观测指向；
  - 对阶段 4 而言，$m$ 所落档 $[L_{k^*}, U_{k^*})$ 的概率直接显式表示为 $p_{\text{lock}} + (1 - p_{\text{lock}}) F_+(U_{k^*} - m)$，高档边际质量由 $(1 - p_{\text{lock}})\Delta F_+$ 独立分配。
- **效果待验（盲测判决）**：
  - *待验假说*：在严格禁止使用 `2019` 的跨年开发池拟合后，Hurdle 架构是否能在**多年度独立盲测集**上同时实现在同源/跨源流下均满足 `ECE_cond(inw) ≤` 预注册离散校准上限、`G3a/G3b` 原子出界收敛至合法区间，且不因午后 $R_t > 0$ 正剩余样本量稀疏而导致 $F_+$ 尾部过拟合或塔性质期望飘移；
  - *验证协议*：须于第四/五章定义的多年度样本外协议与同台 CRPS/ECE 门禁下机械判决（不对未测性能作任何提前断言）。

### 2.2 候选二｜非参数/半参数经验条件分布桥（`方案 β-2`）

- **数学形式**：
  放弃对条件剩余增量设定固定高斯参数族假设，利用训练窗内（如 `608` 天 LST 标准化历史样本与拟扩展的 `2020–2022` 开发池）同站同季同时刻观测状态 $\mathbf{z}_i = (m_i - \mu_{0,i},\; M_{t,i} - X_{t,i},\; \sigma_{0,i})$ 下的实际剩余增量 $R_{t,i} = \max(0, T_{\text{fin}, i} - m_i)$，经由缩放尺度核或状态分桶局部核权重 $w_i(\mathbf{z}_t) \ge 0,\; \sum_i w_i(\mathbf{z}_t) = 1$ 构造条件经验 CDF：
  $$\widehat{G}_t(d \mid \mathbf{z}_t) = \sum_{i \in \mathcal{I}_{s,\text{se},t}} w_i(\mathbf{z}_t) \, \mathbf{1}_{\{R_{t,i}^{\text{scaled}}(\mathbf{z}_t) \le d\}}$$
  其中可对比两种归一化选项：（a）**无缩放直接经验剩余 $R_{t,i}$**；（b）**$\sigma_{\text{rem}}$ 标准差缩放剩余 $R_{t,i} \cdot \frac{\sigma_{\text{rem}}(t)}{\sigma_{\text{rem},i}(t)}$**（保留每日 GEFS 集合离散度的异方差响应）。极端超样本上尾外插由平滑指数尾兜底防止概率坍缩为零。
- **机制对症（结构性归因）**：
  - 逻辑上完全规避参数桥的分布族错配风险（如偏态、截尾双模态、离散取整堆积均在经验分位中自动体现）；
  - $\widehat{G}_t(0^-_{\text{right}})$ 原生等于权重加权之零剩余事件比例，而正增幅直方形状原生由真实样本分布决定，不存在单一曲线同时约束点与尾的强假定。
- **效果待验（盲测判决）**：
  - *待验假说*：面对跨年气候体制漂移（如类似 `2019 Spring` 之偏冷体制）或状态空间高维边缘样本（大冷却深度 $\max(0, M_t - X_t)$ 且大先验偏离）时，有限样本局部核平滑与尺度缩放方式能否保持足够的平滑稳健性、`ECE` 收敛性以及相对于基线的低方差优势；
  - *验证协议*：需检验核带宽与缩放方式在样本外分块交叉验证及多年度盲测上的 CRPS 与 `2°F` ECE 表现。

### 2.3 候选三（独立提案）｜单调条件分位-混合密度桥（`方案 γ`：`Semi-Parametric Mixture / Monotonic Quantile-Spline Bridge`）

- **数学形式**：
  保留连续可微解析 CDF 结构以 100% 兼容阶段 9.7 基于 $\partial p_k / \partial t$ 飘移导数限流机制，同时解除“单成分单高斯”形状锁定，构造**零点原子 + 单峰偏态连续核（混合截断位置-尺度模型，或低维单调分段多项式分位样条）**：
  $$G_t(d \mid \mathbf{s}_t) = \pi_0(\mathbf{s}_t) \cdot \mathbf{1}_{\{d \ge 0\}} + \big(1 - \pi_0(\mathbf{s}_t)\big) \cdot F_{\text{Gamma / JSU}^+}\!\big(d \;\big|\; \nu(\mathbf{s}_t),\, \tau(\mathbf{s}_t) \cdot \sigma_{\text{rem}}(t)\big), \qquad d \ge 0$$
  状态向量取低维物理归一化量 $\mathbf{s}_t = \big(t,\, \frac{m-\mu_0}{\sigma_0},\, \frac{\max(0, M_t - X_t)}{\sigma_{\text{rem}}(t)}\big)$，关键改进在于**端到端联合校准目标**：
  $$\mathcal{L}(\theta) = \lambda_{\text{bin}} \cdot \text{NLL}_{2^\circ\text{F}\text{ brackets}} + \lambda_{\text{crps}} \cdot \text{CRPS}_{\text{bridge}} + \lambda_{\text{tower}} \cdot \big(\mathbb{E}[Y \mid \mathcal{F}_t] - \mu_0\big)^2 + \lambda_{\text{reg}} \cdot \|\Delta^2 \theta\|_2^2$$
  直接将 **`2°F` 离散档似然与连续 CRPS、塔性质约束统一纳入低自由度平滑样条联合优化**，避免检验 A（纯原子）与方案 $\alpha$ Round-2（纯 BCE 缺塔约束）分别走偏的历次失衡。
- **机制对症（结构性归因）**：
  - 同时对症三项物理与工程要求：① $\pi_0$ 与正尾部 $(\nu, \tau)$ 分离解决点-尾耦合；② 保留分族连续解析式与解析导数，无需像纯经验查找表一样在 `Stage 9.7` 退化为粗颗粒差分近似；③ 直接针对最终考核尺度（`2°F` 离散梯子概率 + 连续 CRPS）联合优化，消除“仅用二值残差或仅用连续均值拟合”导致的跨尺度校准错位。
- **效果待验（盲测判决）**：
  - *待验假说*：相比参数更简洁、零额外核假设的 `β-1`（Hurdle）与 `β-2`（经验核），引入联合端到端多目标正则项是否能真正降低过拟合敏感度并在独立跨年盲测集上取得最优综合评分，抑或提升调参复杂度的收益不如预期显著；
  - *验证协议*：与 `β-1`、`β-2` 在完全锁定的多年度开发/盲测切分与统一正则预算下盲选对比，不设优待加权。

## 五、 机械选型判据草案（继承与修订 `G` 门，附噪声预算门槛占位）

遵照 `G-14` 新立之**数值门禁噪声预算制度**，任何具体数字门禁均须基于目标盲测池实际样本量（`2023–2024` ~730 天）计算抽样方差、观测量化项、真值错位项后再正式落定数值。本立项阶段先确立结构框架与指标继承/修订方向（数值占位待噪声预算表落成后填入）：

1. **价值门（`G1'`，继承并发扬）**：
   - `G1'a`：全池 `CRPS_cond < CRPS_native` 且显著低于方案 $\alpha$ 终跑相对表现（同口径下 `CRPS` 与 `RPS` 不得较方案 $\alpha$ 出现有统计学意义退化）；
   - `G1'b`：`station × season × period` 16 分层中改善层数 $\ge 12/16$（或按多年度新增站季维度等比例外推）。
2. **构造物理一致性门（`G2'`，继承）**：
   - `G2'a`（塔性质约束）：全切片期望 $\mathbb{E}[Y \mid \mathcal{F}_t]$ 对无条件先验期望 $\mu_0$ 偏移受控于预注册物理阈值内；
   - `G2'b`（零严重退化）：任意单分层 `CRPS` 劣化比率不超过阈值上限（沿用 `≤ 20%` 为候选基线），且绝不允许违反 $p(U_k \le m) = 0$ 与全概率求和偏差 $\le 10^{-5}$ 物理公理。
3. **离散校准门（`G3'`，修订：纳入多年度 Wilson 上界与双真值视角）**：
   - `G3'a / G3'b`：按目标盲测池实际独立天数重写午后全桶及早段 `B1/B2` 原子残差出界数上限（保留二项 99% 单侧上界与分层加权平均残差上界结构）；
   - `G3'c`：`2°F` 11 档市场尺下全池 `ECE_cond(inw)` 须严格低于**带书面误差预算表之新法定阈值**（草案目标量级在 `≤ 0.015–0.020`，必须同时报告 **GHCN(LST) 同源视角** 与 **OfficialMETAR(DST) 结算视角** 两套数字以确认稳定性，并检查 16 层均匀性防止集中性掩盖）；
   - **程序生效前提**：各门禁具体数字于正式定稿前**必须附带完整的四行误差预算表（抽样噪声 + 观测流离散伪影 + 真值对齐偏差 + 信噪比验证）**，无法覆盖噪声项量级的阈值禁止入档。
