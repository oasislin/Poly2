1. **状态闸门**：点名具体事项前，先核对 [待确认事项登记册](P8-ALGO-REVIEW_待确认事项登记册_20261113.md) 当前状态再展开；
2. **展开与裁决显式分离**：裁决会仅由明确裁决指令触发；非裁决展开输出结尾必须显式标注“需裁决 N 项”；
3. **活队列每轮首行**：每轮推进先确认并更新第四节“活队列”状态；
4. **层次纪律**：业主只裁决方向、优先级与业务口径粒度；技术与算法参数粒度由我方消化或下放开发侧执行；

## 六、 ECE 三层管辖（2026-11-13 裁决）

| 管辖层级 | 口径与阈值 | 触发时点与对象 | 治理语义与处分 |
| :--- | :--- | :--- | :--- |
| **资产门禁** | 气象 `ECE <= 5.0%` | 入库时（Block-CV Binding 级） | 决定模型资产**能否入库服役** |
| **在线治理** | 交易侧 `ECE <= 0.0100` | 服役中（交易侧评估） | 触发挂旗 / 体检评级 / 仓位收缩；**不推翻架构验收结论**，仅降档服役 + 专单修复 |
| **架构验收** | 检验线 `A / B / C` | 架构验收与复训判定 | 决定 `α`（核心模型线）生死；仅复发级结构问题才回退 `β / γ` 逃生通道 |

- **融合落点**：`体检评级 = ECE（校准维）+ 形状距离（形状维，2019 实证基线见 [p8_algo_2019_settlement_shape_distance_20261113.csv](../../evidence/p8_algo_2019_settlement_shape_distance_20261113.csv) / [报告](../../evidence/p8_algo_2019_settlement_shape_distance_20261113.md)） → 绿 / 黄 / 红 → 仓位缩放（1.0x / 0.5x / 0.0x）`。
