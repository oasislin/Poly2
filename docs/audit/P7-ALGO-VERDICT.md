## 总纲：v1 失败归因框架（判决书的裁判总则）

归因已于用户裁决中落定：

- **F-1 数据层**：基本排除（用户裁决：抓取数据问题不大）；
- **F-2 概率层**：确认为根因——v1 模型过于简单，抽检发现分布差异明显。修复路径已定：重抓更多数据、长时间训练；
- **F-3~F-5（防守层/进攻层/样本层）**：合并为不可归因区——F2 失准使上游污染下游，v1 实战表现无法区分三者各自罪责。用户实证：“调整参数总是按下葫芦浮起瓢”——概率层错误之下，任何微观 sizing 调整的效果均被上游误差淹没，故 F3~F5 的机制存废不采信 v1 实战证据，改由第一性原理与 v2 宪法语境裁决。

**F-2 优先律**：概率层（EMOS 分布质量）未经独立验证达标（ECE/CRPSS 门禁 + 抽检分布比对）之前，凯利参数标定与一切 sizing 调优不得开工。微观调整解决不了宏观错误——先修地基，再盖楼。v1 全部教训浓缩于此。本律为 P7-ALGO-2 任务排序的硬前置：凯利数学结构可先写，标定与上线必须等概率层绿灯。

## M-1 · 稳健凯利 Minimax 求解器

**事实层**：v1 strategy.py:172-253 完整实现双层 Minimax：贪心最坏情况概率投影（project_worst_case_probabilities，区间 p_L≤p≤p_U、约束 Σp=1 下最小化 Σp·lnW）+ 外层 SLSQP。参数现值 θ=1.5、η=0.15（config.yaml:26-27）。v2 multinomial_kelly.py 未移植，退化为点估计。（卷宗 4.1）

**裁决姿态**：本机制的 v1 实战证据因 F-2 污染不可采信（不背 v1 的锅，不领 v1 的功），存废改由第一性原理与 v2 宪法语境裁决。

**拷问问题**：

1. θ=1.5 与 η=0.15 出自 3 天样本的反事实 sizing 模拟——这个防守宽度可信吗？η 的物理含义（模型不确定性的下界代理）在样本量 3 天下是否根本无法标定？
2. 防守三重叠加（𝒫 区间 + η 尾部膨胀 + shrinkage）是否就是 F-3？v1 实际下注量与理论凯利的比值有没有记录，缩水到什么程度？
3. 贪心投影算法是近似解——最坏情况排序依赖 wealth_multipliers 排序，在多档位高度相关（温度分布连续）时投影质量如何？
4. v2 移植时必须改造的点：概率不再来自 CHSM 而来自 EMOS 闭式 CDF——std_errors 从哪来？EMOS 的分布参数能否直接给出区间宽度，替代 v1 的经验 std_errors？
5. v2 宪法约束：Active 10（初期更窄）、红级 0.0x 硬拒、四桶资金与 10% 单市场硬顶、全链路 Decimal、ADR-0013 SPECI 截断触发重定价（重定价即重新求解）。

**判词**：（A · 改造移植，2026-10-13 用户签署）：v2 按 EMOS 闭式 CDF 重写结构入规格；标定挂 F-2 锁（θ/η 参数不得继承，等概率层绿灯）。v1 θ=1.5/η=0.15 仅归档不继承。
