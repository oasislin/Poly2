## 一、 预注册四维体检指标与判定标准对照

依 `docs/MODEL_SCORECARD.md` 规定，四维指标及对应绿/黄/红阈值如下：
1. **校准 ECE (加权 20 桶)**：🟢 绿 $\le 0.0100$；🟡 黄 $0.0100 < \text{ECE} \le 0.0200$；🔴 红 $> 0.0200$；
2. **预测偏差 Bias (℉，带符号)**：🟢 绿 $|\text{Bias}| \le 0.50^\circ\text{F}$；🟡 黄 $0.50^\circ\text{F} < |\text{Bias}| \le 1.00^\circ\text{F}$；🔴 红 $> 1.00^\circ\text{F}$；
3. **CRPS 技巧分 (CRPSS vs 气候底座)**：🟢 绿 $\ge 0.150$；🟡 黄 $0.050 \le \text{CRPSS} < 0.150$；🔴 红 $< 0.050$；
4. **90% 区间覆盖率 (Coverage)**：🟢 绿 $[85.0\%, 95.0\%]$；🟡 黄 $[80.0\%, 85.0\%)$ 或 $(95.0\%, 97.0\%]$；🔴 红 $< 80.0\%$ 或 $> 97.0\%$。

**总评与治理规则**：
- **短板定级（Lowest-Pillar Decides）**：全绿 = 🟢 可投（正常 1.0x 头寸）；任一黄且无红 = 🟡 带旗收缩（0.5x 头寸，禁单向加仓）；任一红或未审 = 🔴 禁投（0.0x 头寸，禁开新仓）。
