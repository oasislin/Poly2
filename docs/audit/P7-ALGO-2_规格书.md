## 1. 算法目的与范围

**目的**（方案 v2.8 §1、§6 提取）：将 EMOS 概率层的物理优势无损转化为账户 pUSD（backed by USDC）的安全稳健复利增长——在互斥离散档位市场上（依站点温标 `temperature_unit` 划分 2°F 或 1°C 档位），**EV 决定方向，凯利决定规模，风控决定放行，执行决定价格**，全程只买不卖、向前对冲、本金保护优先。

**范围边界**：
- **输入**：EMOS 概率层输出（每档截断后概率 p̂，Σp̂=1）；Polymarket CLOB 盘口（每档 ask/bid 深度）；市场元数据 market_meta（tick_size, minimum_order_size, fee_rate, temperature_unit, station_tz 等）；账户状态（四桶资金、既有持仓、僵尸仓位）；台站状态（生命周期、截断状态、观测新鲜度）；参数（费率、门禁阈值）。
- **输出**：每档目标买入金额 f* → 批准金额 x_approved → FAK 限价订单（未成交部分立即取消）与成交记录 → 四桶账务变更。
- **不产生概率**：本规格只消费、不修正概率层输出（P1 原则；F-2 优先律）。

- **S6 已降级为只读错价监控**（2026-10-19 定论，DR-2026-1019-01）：三轨套利废除（公理+机制+实证），不再占用资金、不进入交易管线；Q2"套利前置最高优先级"裁决作废留痕；

## 4. 模块规格

### M1 定价引擎（Pricing）
- **职责**：盘口深度 → 有效成本 q_eff；EV/edge 信号；带旗/FAILSAFE 判定；可交易信号。
- **关键算法**：
  1. **定价穿透规模自动确定（DR-2026-1014-01）**：探针规模 $S_{\text{target}} := \sum_{j: \text{edge}_j \ge \text{min\_edge}} s_j = \text{safe\_capacity\_at\_min\_edge}$，定价纯盘口均价 $\bar P$ 自动取达标深度加权均价，无需外部传入随意猜测，根除"鸡生蛋"死锁；
  2. **动态费率折算**：先纯盘口均价 $\bar P$，再 $q_{\text{eff}} = \bar P \cdot [1 + 0.05 \cdot (1 - \bar P)]$，**严禁逐层非线性费率迭代**；base 经市场契约 v1.0 闭环定案为 **0.05**；暂不做 maker，返佣不建模；$\text{net\_ev} = \hat p - q_{\text{eff}}$；$\text{edge} = \text{net\_ev} / q_{\text{eff}} \ge \text{min\_edge}$。
- **输入**：订单簿快照、p̂、market_meta、费率参数、治理旗。**输出**：每档 (p̂, q_eff, edge, tradable_flag, governance_multiplier)。
- **治理（用户裁决 A）**：带旗资产 **tradable_flag = False**（不交易、只观测，直至拔旗）；FAILSAFE 只读；无折剪参数（折减点因 A 方案取消）。

### M2 凯利优化器（Kelly Sizing，本规格核心）
- **职责**：互斥档位间预算分配（多项对数财富增量最大化 + 稳健化 Minimax）。
- **数学与求解突破（P0-2 外部审计修正）**：
  - 彻底废除内层 argsort 离散贪心投影引起的非光滑极点翻转与 SLSQP 线搜索假死；
  - 严格采用 **LP 强对偶单层连续可微展开（$3K+1$ 维变量）**：将内层最坏概率极小化对偶化并与外层极大化合并，目标函数为关于对偶变量的严格线性函数，耦合约束 $\ln W_i(f) - \lambda - \alpha_i + \beta_i \ge 0$ 为凹函数上水平集（凸集），构成在闭凸集上的严格凸规划；
  - SLSQP 求解器配置解析闭式 Jacobian 梯度向量，收敛性与全局最优性由凸优化强对偶定理完备保证。
- **预算前置唯一化（DR-2026-1014-02）**：风控调制系数 $\tau_z$ 与 $\tau_{\text{2D}}$ 前置并入预算上限公式：
  $$C_{\max} := \tau_z \cdot \tau_{\text{2D}} \cdot \min(0.10 B_{\text{eff}}, 0.70 B_{\text{eff}} - \text{Active\_locked}, W_{\text{free}})$$
- **输入**：每档 (p̂, q_eff)、W_free、既有持仓 N、预算上限 $C_{\max}$、`eps: float = 1e-7`。**输出**：f*（或 fail-closed 全零）。
- **挂锁**：θ、η、δμ、δσ 全部 `[F-2 LOCKED]`；结构先行落地。

### M3 风险闸门（Risk Gates）
- **职责**：对 f* 施加宪法级硬顶与门禁，输出批准分配 x_approved。
- **折剪点唯一化与纯布尔放行（DR-2026-1014-02 裁决改写）**：
  - 风控调制已前置并入 S2 预算上限 $C_{\max}$ 公式，**S3 风险闸门转为纯布尔放行（无任何后置乘法调制）**；
  - 彻底杜绝"先求 $f^*$ 再后置乘 $\tau$"导致各档金额碎屑化而被 `minimum_order_size` 团灭的工程隐患；
  - 门禁链全部下沉为代码布尔函数：G1 单市场 10% / G2 全局 70%（分母统一 $B_{\text{eff}}$）/ G3 僵尸门禁（$\tau_z > 0$）/ G4 无量纲标准化残差阶梯风控门禁（$\tau_{\text{2D}} > 0$）/ G5 带旗禁投 / G6 预购门与元数据门 / G7 求解器收敛与破产保护（$W_i \ge \text{eps}$）。

### M4 执行路由（Execution）
- **职责**：x_approved → 保护价 FAK 限价单（未成交部分立即取消） → 成交 → 残差愈合 → 资金锁解。
- **关键算法与精度守恒（P0-3 修正）**：
  1. 保护价 $P_{\text{protect}}$ 计算（遍历 ask 档锁定最后一个满足 net_ev / q_eff ≥ min_edge 档位）与 safe_capacity；
  2. 严格 5 步向下整取量化管道：
     - $f_i^*$ 经 6 位 Decimal ROUND_DOWN；
     - $P_{\text{protect}}$ 按 tick_size 实行 ROUND_DOWN；
     - **含费折算原始份额与深度截断（P0-3）**：$S_{\text{raw}} = \min(f_i^* / q_{\text{eff}}(P_{\text{protect}}), \text{safe\_capacity})$；
     - 份额按 lot_size 实行 ROUND_DOWN：$S_{\text{final}} = (S_{\text{raw}} // \text{lot\_size}) \times \text{lot\_size}$；
     - 门禁检查：若 $S_{\text{final}} < \text{minimum\_order\_size}$，标记 `SKIPPED_BELOW_MINIMUM_ORDER_SIZE` 释放资金；
  3. **资金含费足额预冻结（P0-3）**：`lock_funds(S_final * q_eff(P_protect))`，杜绝扣费导致资金池透支；
  4. 下发 FAK 限价单至 CLOB 网关；**严禁市价单**（`MarketOrderForbiddenError`）；
  5. 残差状态机（CLEAN / RESOLVED_BALANCED / STOP_LOSS_TRIGGERED / LIQUIDATED）；
  6. **追单贴水上限（P1-4）**：ResidualHealer 追单重对冲允许最大亏损比例 `max_rehedge_loss: Decimal = Decimal("0.02")`（`[待标定]`），超阈值触发止损平仓。

### M5 资金账务（Bankroll）
- **职责**：四桶恒等（Total = Free + Active + Zombie + Disputed）、**pUSD（backed by USDC）单币种绝缘计价**、Decimal 6 位截断、双轨估值（sizing 母数 0.0x / NAV 90% 折价）、僵尸分级熔断（R_z：15/30/50 → HEALTHY/WARNING/HALT/SAFE_MODE）。
- **利用率分母统一（DR-2026-1014-03 / ADR-0012 联动）**：全局流动性占用率统一以有效资金母数 $B_{\text{eff}}$ 为分母：
  $$\text{Utilization} = \frac{\text{Active Locked} + \sum f_i}{B_{\text{eff}}} \le 0.70$$
  Zombie Margin 与 Disputed Margin 分子分母坚决全剔除，贯彻审慎风控底线。

### M6 错价观测（Read-Only Misprice Monitor，原套利通道降级）

- 三轨套利（轨 A 全包 YES / 轨 B 全包 NO / 轨 C 单档配对）已于 2026-10-19 **全部废除**（DR-2026-1019-01）：结算公理 Σp=1、链上 split/merge 固定汇率 $1/对、套利机器人秒级闭合、真实盘口 ΣAsk(YES)=1.0170>1——不存在可触发的无风险锁利空间；
- **保留只读观测**：① 单档互补偏离 Ask(YES_i)+Ask(NO_i)−1；② 跨档总和偏离 ΣAsk(YES_i)−1；低频轮询 + 超阈值告警日志；
- **零发射硬约束**：不触发任何下单、不产生仓位、不进入交易管线；原冻结条款（前置优先、豁免 C_loc、DUTCH_BOOK_DISPATCH、并发 FAK）**全部废止**。

### M7 结算复刻（Settlement）
- **职责**：按 NWS WRH（ADR-0012）复刻结算、回笼资金、12h 僵尸触发、逾期处置、Decimal ROUND_HALF_UP 整度舍入口径。
- **物理锚点**：距名义到期剩余时间 $t_{\text{remain}}$ 严格锚定至**台站当地自然日 23:59:59**（依 `station_tz` 解析，DR-2026-1014-04）。

### M8 标定与验证（Calibration/Sim）
- **职责**：纸面盘 / 回测 / 两步标定（重定义后：Step 0 概率门禁审计 + Step 1 反事实 sizing）。
- **冻结条款**：交易层不重标气象参数；θ/η 标定数据等纸面盘自产；直连 **Data API v2**（端点 `/v2/prices-history`，cursor 分页 + 本地 Airgap Cache + RateLimiter 18/s）；全套代码可先完备编写（M-8）但运行命令与参数落地 `[F-2 LOCKED]`；2019 盲测年 Airgap 作验证通道。

### M-G 异常治理（横切）
- **职责**：Incident 契约（子系统/严重度/原因码）、事件总线、台站生命周期（ACTIVE/SUSPENDED/INVALIDATED/EMERGENCY_HALT）、本地硬阀（零发射定理）、30s 重试预算、连续失败上报（含 SLSQP 连续 N 次失败联动）。

## 5. 门禁体系与判定下沉

所有门禁判定**下沉为代码布尔量**（`pass = value >= threshold` 形式），agent 只读结果不做数值比较（项目铁律）：

1. **概率层门禁（F-2 上游）**：RED（Binding ECE > 5% → 全线熔断）/ YELLOW（交易窗口 ECE > 0.0100 → 带旗禁投）/ GREEN（双达标 → 解锁标定）。口径继承声明，版本更新协同留痕。
2. **预购门与元数据门（G6）**（ADR-0014）：Δage ≤ 7min ∧ 数据连通 ∧ 网关连通 ∧ 静态元数据完备校验 ∧ ACTIVE ∧ 阀开。
3. **带旗治理门（G5）**：governance_flag is None。
4. **求解器收敛门（G7）**：SLSQP 收敛 ∧ 无 NaN ∧ $W_i \ge \text{eps}$。
5. **两维风控门禁（G4）**（DR-2026-1014-04）：改用无量纲标准化残差 $z = \frac{|T_{\text{obs}} - \hat{\mu}_{\text{EMOS}}|}{\hat{\sigma}_{\text{EMOS}}}$；当 $z > z_{\text{crit}}$ 且 $t_{\text{remain}} \le 15\text{m}$ 时判定为 CRITICAL 危险区，$\tau_{\text{2D}} = 0$ 触发 G4 布尔阻断；平时 $\tau_{\text{2D}} > 0$ 布尔放行。
6. **僵尸熔断门禁（G3）**：当 $R_z > 30\%$ 时 $\tau_z = 0$ 触发 G3 布尔阻断；平时 $\tau_z > 0$ 布尔放行。
7. **单市场 10% 硬顶（G1）**：$\sum f_i \le 0.10 \cdot B_{\text{eff}}$。
8. **全局 70% 利用率硬顶（G2）**（DR-2026-1014-03）：$(\text{Active Locked} + \sum f_i) / B_{\text{eff}} \le 0.70$。

## 6. 数据流与接口要点

1. S1→S2：每档 (p̂, q_eff, tradable_flag) 及 market_meta 快照（含 `temperature_unit`, `station_tz`）；不可交易档强制 $f_i = 0$；
2. S2→S3：f* + 优化器状态（收敛/退化）；
3. S3→S4：x_approved + G1~G7 全部布尔通过证据（`ALL_SYSTEMS_PASS = True`）；
4. S4→S5：成交明细 → 四桶更新；
5. S5→S2（回环）：持仓沉没成本向量 N；
6. M-G：任何模块异常 → Incident → 台站状态变更 → 回灌 S3/S4。
