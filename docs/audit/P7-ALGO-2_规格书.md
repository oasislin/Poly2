## 1. 算法目的与范围

**目的**（方案 v2.8 §1、§6 提取）：将 EMOS 概率层的物理优势无损转化为账户 USDC 的安全稳健复利增长——在互斥 2°F 离散档位市场上，**EV 决定方向，凯利决定规模，风控决定放行，执行决定价格**，全程只买不卖、向前对冲、本金保护优先。

**范围边界**：
- **输入**：EMOS 概率层输出（每档截断后概率 p̂，Σp̂=1）；Polymarket CLOB 盘口（每档 ask/bid 深度）；账户状态（四桶资金、既有持仓、僵尸仓位）；台站状态（生命周期、截断状态、观测新鲜度）；参数（费率、门禁阈值）。
- **输出**：每档目标买入金额 f* → 批准金额 x_approved → IOC 限价订单与成交记录 → 四桶账务变更。
- **不产生概率**：本规格只消费、不修正概率层输出（P1 原则；F-2 优先律）。

## 3. 端到端流程（7 阶段管线 + 横切层）

```
EMOS 概率层 ──▶ S1 定价/信号 ──▶ S6 套利扫描 ──▶ S2 凯利Sizing ──▶ S3 风控闸门 ──▶ S4 执行路由 ──▶ S5 持仓/资金
(F-2管辖)      │EV/edge/带旗判定 │独立无风险通道   │目标f*          │批准分配        │IOC成交/残差   │四桶+旧持仓回环
                 └────────────── S7 结算与验证闭环（纸面盘/回测/两步标定，挂F-2锁）──────────────┘
横切 M-G：异常治理（Incident总线/硬阀/台站生命周期/预购门）贯穿 S1~S7
```

- **S6 前置于 S2**（冻结于 Debate Q2）：无风险套利享有最高优先级，剩余资金与最新持仓再注入 S2 凯利增量对冲；
- **S5→S2 回环**："向前对冲"机制载体——当前持仓（沉没成本 payout 向量）作为下一轮凯利外生输入；
- **决策快照冻结（N3，宪法级）**：一次决策周期内，概率 / 盘口 / 不确定集边界 / 费率参数全部冻结，杜绝半更新状态与脏读（对齐 ADR-0011 D5）。

## 4. 模块规格

### M1 定价引擎（Pricing）
- **职责**：盘口深度 → 有效成本 q_eff；EV/edge 信号；带旗/FAILSAFE 判定；可交易信号。
- **关键算法**：VWAP 深度穿透（按目标规模累计 ask 档）→ 动态费率折算（先纯盘口均价 P̄，再 q_eff = P̄·[1+base·(1−P̄)]，**严禁逐层非线性费率迭代**）；net_ev = p̂ − q_eff；edge = net_ev / q_eff ≥ min_edge。
- **输入**：订单簿快照、p̂、费率参数、治理旗。**输出**：每档 (p̂, q_eff, edge, tradable_flag, governance_multiplier)。
- **治理（用户裁决 A）**：带旗资产 **tradable_flag = False**（不交易、只观测，直至拔旗）；FAILSAFE 只读；无折剪参数（折减点因 A 方案取消）。

### M2 凯利优化器（Kelly Sizing，本规格核心）
- **职责**：互斥档位间预算分配（多项对数财富增量最大化 + 稳健化 Minimax）。
- **数学**：见《算法描述文档》§3~§6（目标函数、凹性、不确定集、贪心投影、SLSQP）。
- **输入**：每档 (p̂, q_eff)、W_free、既有持仓 N、预算上限。**输出**：f*（或 fail-closed 全零）。
- **挂锁**：θ、η、δμ、δσ 全部 `[F-2 LOCKED]`；结构先行落地。

### M3 风险闸门（Risk Gates）
- **职责**：对 f* 施加宪法级硬顶与门禁，输出批准分配 x_approved。
- **门禁链（全部为硬性不等式，见《算法描述文档》§7）**：单市场 10% / 全局 70% / 僵尸分级折剪 / 两维风控调制 / 带旗禁投 / 预购门（7min 新鲜度 + 连通 + ACTIVE + 阀开）。
- **折剪点唯一化（N1 冻结）**：宪法硬顶与调制全在 S3 实施；治理折剪不存在（带旗禁投）；两处不叠加。

### M4 执行路由（Execution）
- **职责**：x_approved → 保护价 IOC 限价单 → 成交 → 残差愈合 → 资金锁解。
- **关键算法**：保护价计算（遍历 ask 档锁定最后一个正 EV 档）、safe_capacity、IOC 单、严禁市价单（MarketOrderForbiddenError）、残差状态机（CLEAN / RESOLVED_BALANCED / LIQUIDATED）。
- **输入**：x_approved、盘口、台站状态。**输出**：订单、成交明细、资金变更。

### M5 资金账务（Bankroll）
- **职责**：四桶恒等（Total = Free + Active + Zombie + Disputed）、Decimal 6 位截断、双轨估值（sizing 母数 0.0x / NAV 90% 折价）、僵尸分级熔断（R_z：15/30/50 → HEALTHY/WARNING/HALT/SAFE_MODE）。
- **输入**：订单、结算、僵尸判定。**输出**：余额、锁解、B_eff。

### M6 套利通道（Arbitrage，独立旁路）
- **职责**：无风险机会扫描与锁利（Dutch Book 判定、反向 NO、全包 YES）。
- **冻结条款**（Debate Q2 + 主导方补充）：前置优先；豁免 C_loc；上限 min(Free, C_total − Active)；**计入 Active Locked，70% 全局利用率不豁免**；上限受盘口现实可成交深度约束；经 ADR-0014 登记（DUTCH_BOOK_DISPATCH）；**不走凯利目标函数**；margin_dutch 为新参数不继承（`[待标定]`）。

### M7 结算复刻（Settlement）
- **职责**：按 NWS WRH（ADR-0012）复刻结算、回笼资金、12h 僵尸触发、逾期处置、Decimal 舍入口径。

### M8 标定与验证（Calibration/Sim）
- **职责**：纸面盘 / 回测 / 两步标定（重定义后：Step 0 概率门禁审计 + Step 1 反事实 sizing）。
- **冻结条款**（Debate Q4）：交易层不重标气象参数；θ/η 标定数据等纸面盘自产；v1 历史样本不作先验；全套代码可先完备编写（M-8）但运行命令与参数落地 `[F-2 LOCKED]`；2019 盲测年 Airgap 作验证通道。

### M-G 异常治理（横切）
- **职责**：Incident 契约（子系统/严重度/原因码）、事件总线、台站生命周期（ACTIVE/SUSPENDED/INVALIDATED/EMERGENCY_HALT）、本地硬阀（零发射定理）、30s 重试预算、连续失败上报（含 SLSQP 连续 N 次失败联动）。

## 5. 门禁体系与判定下沉

所有门禁判定**下沉为代码布尔量**（`pass = value >= threshold` 形式），agent 只读结果不做数值比较（项目铁律）：

1. **概率层门禁（F-2 上游）**：RED（Binding ECE > 5% → 全线熔断）/ YELLOW（交易窗口 ECE > 0.0100 → 带旗禁投）/ GREEN（双达标 → 解锁标定）。口径**继承声明**：继承自模型训练/抽检阈值设定，交易层只消费判定结果；**联动调整契约**：版本更新时概率层/交易层协同调整、两侧确认、留痕、回灌门禁（用户确认）。
2. **预购门**（ADR-0014）：Δage ≤ 7min ∧ 数据连通 ∧ 网关连通 ∧ ACTIVE ∧ 阀开。
3. **两维风控**（ADR-0011）：CRITICAL → 0.20x；CERTAIN → 禁反向；NORMAL → 1.00x。
4. **预算硬顶**：Σf ≤ 0.10·B_eff；利用率 ≤ 70%；僵尸分级折剪系数 τ_z。
5. **求解器 Fail-Closed**：SLSQP 未收敛/含 NaN → 全零向量 + 诊断上报；连续 N 次 → ADR-0014 联动。

## 6. 数据流与接口要点

1. S1→S2：每档 (p̂, q_eff, tradable_flag)——不可交易档不进凯利；
2. S6→S2：套利占用后剩余 Free + 最新持仓注入；
3. S2→S3：f* + 优化器状态（收敛/退化）；
4. S3→S4：x_approved + 门禁通过证据（供审计）；
5. S4→S5：成交明细 → 四桶更新；
6. S5→S2（回环）：持仓沉没成本向量 N；
7. M-G：任何模块异常 → Incident → 台站状态变更 → 回灌 S3/S4。
