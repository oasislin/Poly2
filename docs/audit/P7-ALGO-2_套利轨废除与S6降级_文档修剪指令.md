### G1. P0-2 挑战点表述注记（算法描述 §6 引理 2/3 + 工程落档细化 §4.x 对应行）

**问题**：挑战分析指出 P0-2 三处表述瑕疵，文档仍为原样（不严谨表述可能误导后续数学推导）：
- 算法描述 §6 **引理 2**（原 L163）："耦合函数 $g_i$ 是仿射函数与对数函数的复合，**严格为凹函数**；其水平集……是**严格闭凸集**"——`ln W_i(f)` 为凹函数（仿射函数的对数），**未必严格凹**（存在线性方向/退化档位时非严格）；凸集无"严格"修饰，应写"闭凸集"；
- 算法描述 §6 **引理 3**（原 L165）："SLSQP 在给定解析 Jacobian 下**保证收敛至 KKT 点，即全局唯一最优解**"——**过强**：线性目标在闭凸集上最优解**可能非唯一**（最优解集为凸面而非单点）；数值 SLSQP 亦**不保证 100% 成功**（浮点、缩放、退化场景）；
- 工程落档细化 L557："耦合约束（**复合严格凹函数**，水平集为闭凸集）"——同款"严格凹"表述。

**修正方式**（仅加严谨性注记/措辞修正，**不改公式、不改结构、不动 Fail-Closed 机制**）：

1. 算法描述 §6 引理 2：`严格为凹函数` → `为凹函数（一般情形非严格凹：存在线性方向时凹性退化）`；`严格闭凸集` → `闭凸集`（两处）；
2. 算法描述 §6 引理 3：末尾追加一句："**注**：凹性保证全局最优，但线性目标的最优解集可能非唯一（凸面）；数值 SLSQP 不保证 100% 收敛——**G7 Fail-Closed 兜底保留为第二道物理防线**（对偶化负责常态收敛率，Fail-Closed 负责退化兜底，二者互补）"；
3. 工程落档细化 L557：`复合严格凹函数` → `复合凹函数`（同步措辞）；
4. 头部"已对齐"注明"P0-2 严谨性注记（2026-10-19）"。
