## 一、 内核六条

### D-1 赚钱逻辑 `✅ 已定稿`

$$\text{edge} = \text{我们的校准分布} - \text{市场隐含概率} - \text{摩擦（价差} + \text{冲击} + \text{安全垫）}$$

- **参照系原则**：参照系是**市场价格**，不是绝对真值；不需要全局最准，只需比盘口隐含价格更准且概率校准可靠。
- **未实测声明（硬约束）**：截至 `2026-11-16`，系统盈利性尚未实测；上述三项前提假设（校准优势存在、摩擦可覆盖、盘口深度可容纳）**全部待真实盘口数据验证**，禁止提前预设收益。

### D-2 市场结构 `✅ 已定稿`

- 天气盘整体深度较低，参与者结构以散户为主（`> 70%`，*注：具体统计出处待补入档核验*）；做市商实质承担**收费流动性通道**角色而非信息型强对手盘。
- 资金容量特征为**小而稳**；仓位上限自改版运行**第一天起按盘口实时深度倒推**，不得先拍资金上限再强塞盘口。

### D-3 系统形态与历史误区澄清 `✅ 已定稿`

- **三段真实生产形态**：
  1. **GFS 翻译层**（全程生效，覆盖远期至日内先验输出）；
  2. **桥收敛层**（临近观测窗激活，依据日内实况推进条件收敛）；
  3. **结算口径适配**（目标靶 = `G-15` 结算源对齐）。
- **`max` 恒等式驱动之条件分布天然形态**：由日最高温单调极值约束 $T_{\max} \ge M_t$（$\max$ 恒等式），条件剩余分布天然呈 **“点质量（不创新高锁顶原子）+ 条件超越（突破 $M_t$ 后之正增幅连续分布）”** 双成分形态。
- **重要澄清入档（严禁误用历史指标）**：
  - **生产线自始至终消费 GFS（GEFS）预报先验**；
  - 检验 C 中使用的**气候学先验（`CRPS_native` / `Climatology` 实验隔离基线）仅是离线实验对照手段，并非系统生产真实形态**；
  - 检验 C 归档数据中的 **`−48.3%`（`−48.33%`）属于相对气候学基线对照之实验功劳簿，严禁在后续任何改版收益预期、立项论证或盈利测算中引用**。

### D-4 桥的处置与“生产即测绘”新范式 `✅ 已定稿`

- **废止前置合流测绘协议**：原拟前置验证协议彻底废止（核心事实原因：`2020–2024` 完整历史配套数据并不存在，外部回填周期与质量均为未知数）。
- **生产即测绘**：条件桥随本次架构改版直接进入生产路径，在**冻结运行期**内持续采集全量 **四元组日志**：
  1. **决策上下文**（时刻、台站、日内状态、冻结模型版本与参数快照）；
  2. **模型侧**（GFS 先验参数、桥输出分布、`p_stay` 锁顶原子、条件档位概率）；
  3. **市场侧**（实时盘口深度/价差被动记录快照）；
  4. **结算侧**（官方最终结算温度与中奖档位）。
- **新盲池定义**：**每个冻结运行周期完整沉淀的生产四元组日志，直接作为下一轮审计评估与复检的独立盲测池**。

### D-5 交易理念 `✅ 已定稿`

- **持仓周期**：以**持有至结算**为主，不主动追逐短线博弈噪点。
- **概率驱动退出规则**：**不设主观价格阈值**；当实时更新的条件概率分布与当前盘口隐含价格发生显著交叉（重算持仓继续持有期望 vs 立即卖出兑现期望并计入退出摩擦）时，由期望值对比机械触发减仓或清仓退出。
- **执行节奏**：**多次、少金额、中频扫描**（契合低深度、小而稳容量特征）。

### D-6 制度合龙 `⬜ 下一桌议程（待产出一份三段式文档）`

- **现状断点**：用户原有的“训练 → 抽检 → 亮灯（绿/黄/红）”气象评估治理体系尚未与投注交易算法合龙，存在三项明确断点：
  1. **判定对象未对齐**：红黄绿“亮灯”的判定对象尚未对齐到交易侧最小决策级；
  2. **映射缺失**：尚不存在客观统一的 **“灯 → 钱（仓位/额度系数）”映射表**；
  3. **考核孤岛**：气象模型考核制度与交易侧考核制度尚未合并为同一套管辖规程。
- **下一桌唯一交付物目标**：产出 **1 份完整合龙文档**，明确包含三段：
  1. **抽检定义**；
  2. **亮灯规则**；
  3. **灯到钱映射表**。
