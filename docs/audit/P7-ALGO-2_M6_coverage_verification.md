# P7-ALGO-2 M-6 截断层覆盖性验证（CHSM 场景清单 vs ADR-0013 + v2 对应物）

> **文档编号**：P7-ALGO-2-M6-COV  
> **日期**：2026-10-13  
> **目的**：履行判决书 M-6 判词前置条件——"ADR-0013 截断层场景清单覆盖性验证后正式落笔"（REMEDIATION_PLAN §五 M-6 附条件）  
> **验证对象**：CHSM（条件高斯自回归蒙特卡洛，ρ=0.85、100 samples/member）在 v1 承担的全部场景，是否在 v2（ADR-0013 截断层 + EMOS 体系）有完整对应物，**无遗漏场景**  
> **证据源**：判决书 M-6、凯利溯源卷宗 §4.6、ADR-0013（D1~D5）、ADR-0015、M-1 判词、方案 v2.8

## 一、CHSM 承担场景清单（v1，来源：卷宗 §4.6 + 判决书 M-6）

CHSM 在 v1 `analyst.py` 中实现，核心思想="日内已发生实况 + 未来推演"（判决书 M-6 拷问）。逐项分解其承担的场景：

| # | CHSM 场景 | 内容 |
| :--- | :--- | :--- |
| S1 | **日内实况融合** | 以当日已发生的观测温度（SPECI/例行报）通过自回归 ρ=0.85 条件化成员轨迹——"已发生实况"进入概率推断 |
| S2 | **未来推演** | 从当前状态外推至结算时刻的温度极值分布（TMAX 取 max / TMIN 取 min） |
| S3 | **档位概率生成** | 蒙特卡洛样本落入 2°F 档位的频率 → 各档位概率估计（含抽样误差 se_MC，供不确定集使用） |
| S4 | **发散下限防护** | 防止模拟分布发散过窄（v1 标定方案 Baseline_σ 下限） |

## 二、v2 对应物映射（覆盖 / 替代 / 增量）

| CHSM 场景 | v2 对应物 | 对应类型 | 依据 |
| :--- | :--- | :--- | :--- |
| S1 日内实况融合 | **ADR-0013 D1：SPECI 零延迟单向截断**（TMAX←max、TMIN←min，单调收紧，死档概率置 0，毫秒级撤单） | **覆盖（截断层）** | ADR-0013 D1；判决书 M-6（"对应物为 ADR-0013 SPECI 单调截断"） |
| S2 未来推演 | **EMOS 闭式 CDF（三族池）** + ADR-0013 D1 截断触发重定价（重新求解） | 替代（EMOS） | 判决书 M-1 拷问 5；方案 v2.8 |
| S3 档位概率生成 | **EMOS 三族池闭式 CDF 解析计算**（确定性可微，蒙特卡洛不回流=宪法要求）；se_MC → **M-1 判词：不确定集宽度由 EMOS CDF 参数派生（Delta Method）** | 替代（EMOS + M-1 改造） | 判决书 M-6 v2 宪法约束；M-1 判词 |
| S4 发散下限 | **ADR-0015：σ_inst=0.9°F 物理底座 + σ² = c² + d²·S_ens²**（废除加法项后的方差结构自带下限） | 替代（ADR-0015） | ADR-0015 |

**v2 增量（v1 CHSM 无对应、为新增防御，不构成遗漏）**：
- ADR-0013 三道纯温门禁（气候极值域 / 正文-RMK 1.8°F / 单步 15°F）——数据异常检测（v1 CHSM 直接消费实况，无独立门禁）
- ADR-0013 D2 迟到不投 / D3 三步 Fail-Closed 熔断 / D4 对称截断 / ADR-0014 统一仲裁——数据不可靠时的阻断防御（v1 无对应）

## 三、验证结论

1. **CHSM 承担的 4 类场景（S1~S4）在 v2 均有对应物**：S1 由 ADR-0013 截断层**覆盖**（判词要求的覆盖对象）；S2~S4 由 EMOS 体系与 ADR-0015 **替代**（宪法级：蒙特卡洛不回流，替代即正确处置，无需"覆盖"）。
2. **无遗漏场景**：逐项比对 CHSM 全部职责后，未发现 v2 缺失任何 CHSM 原有功能场景。
3. **判定**：截断层覆盖性验证 **通过**。M-6 判词可正式落笔"确认废弃"（由解析 EMOS 三族池替代，蒙特卡洛不回流）。
