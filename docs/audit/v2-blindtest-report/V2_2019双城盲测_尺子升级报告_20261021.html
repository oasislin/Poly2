2. V2.0 新尺子四模块（替代 V1 固定工程带）

模块定义与 V1 的区别
Q2/Q3 s_oos由残差 lag-1 ρ₁ 算 N_eff=n·(1-ρ₁)/(1+ρ₁)，并列 Finf 带（χ²/N_eff）与 Fstd 带（F(N_eff,n-1)）95% 动态非对称带；浮点 N_eff 直传 ppf替代 V1 固定对称 [0.85,1.15]；双带并列、无法定二选一
Q4 均匀性KS + CvM 双检验方案乙：仅当 KS p<0.05 且 CvM p<0.05 才 reject_uniform避免 n≈365 下 KS 临界点悬崖误杀，任一 p≥0.05 不否决
Q5 ECE11 档（左 catch-all + 9 个 2°F 内部档 + 右 catch-all）档级直接可靠性 ECE；bins10/bins20 等宽概率桶敏感性；ece_range 为四口径极差替代 V1 7 档 ±3°F 自定窗（KORD 41%~71% 窗外漏检）
Q6 PITPIT 样本方差（理论均匀 1/12=0.08333）+ 10 档等宽直方图占比形态背景诊断，非法定门
