## 三、补注内容：τ_2D 完整阶梯映射（结构式，数值挂锁）

请将 G4 表述补全为以下结构（数值一律 `[待标定]`，不得填定稿实值；可保留参考基线并标注）：

| 档位 | 触发条件（结构） | τ_2D 取值 | 备注 |
| :--- | :--- | :--- | :--- |
| 正常 | 非以下各档 | **1.0** | 全预算（已前置进 C_max） |
| CRITICAL 缩放 | `z_cert < z ≤ z_crit_scale` ∧ `t_rem ≤ 60m` | **0.20** | 承接原 ADR-0011 "T_rem<1h ∧ ΔT>3°F → 0.20x" 的 z 口径对应 |
| CERTAIN 方向限制 | `z ≤ z_cert`（预测几乎确定） | 正向 **1.0** / 反向 **0** | 承接原 "CERTAIN → 禁反向投机"：反向开仓（与预测相反方向）一票否决，正向不受缩放 |
| 极端阻断 | `z > z_crit_scale` ∧ `t_rem ≤ 15m` | **0** | 现有阻断档（全阻断，C_max=0） |

**要点**：
- τ_2D 取值域：`{1.0, 0.20, 0}`，加 CERTAIN 方向性（反向 0）；
- 阈值：`z_cert`（参考基线 0.3）、`z_crit_scale`（参考基线 2.0）——均标注 `[待标定]`，F-2 绿灯后经两步标定定稿；
- 原 °F 绝对阈值（0.5°F / 3°F）保留为**换算对照基线**写在表注（σ≈1.5°F 时对应 z≈0.33 / 2.0），供审计追溯，不作为运行时数值；
- **不得改变已验收结构**：τ 前置进 C_max（DR-2026-1014-02）保持不变；S3 门禁布尔 `τ_2D > 0` 放行逻辑保持不变（0.20 档同样放行）。
