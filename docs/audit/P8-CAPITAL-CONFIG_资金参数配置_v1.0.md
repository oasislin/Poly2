### 1.5 UTC 日部署上限与网关金额双闸口径（`v1.1` 新增 · `2026-11-22` 业主授权）

- **“UTC 日部署上限”正式定义**：UTC 自然日界（`00:00:00Z–23:59:59Z`）内，账户级 **新增买入实盘订单** 累计资金防护闸（独立于 `M4/M6` 资金门的第二道网关硬防线）：
  1. **发单前阻断口径**：`当日已成交买入 + 在途预留 + 本笔最大名义额（limit_price × target_shares） <= max_daily_cumulative_usd`，超出即本地拒绝、零触网；
  2. **入账累计口径**：仅计实际成交名义额（`FILLED / PARTIAL`）；**手续费单列 `fee_paid_usd` 科目**；未成交余款即时释放；
  3. **卖出语义**：卖出不占用买入部署额度，亦**严禁逆向冲减**当日已累加买入额度；
  4. **跨重启持久化**：计数器必须跨进程重启持久保存；**`daily_ledger_path` 配置化为 [`configs/clob_gateway.yaml`](../../configs/clob_gateway.yaml) 必填项**（代码中校验强制化随 `S3-14` Runner 开发单落实）。
- **常态日部署基准与双闸公式**：
  $$D_{\text{deploy}} = \min\!\left(\frac{\text{当期有效资金池 } P_{\text{tier}}}{\text{持仓周期 } D_{\text{hold}}},\; \text{活跃站数 } N \times B\right)$$
  $$\text{常态日闸} = k_{\text{safety}} \times D_{\text{deploy}}, \qquad k_{\text{safety}} \in [1.25,\; 1.5]\ \text{（缺省 } 1.5\text{）}$$
- **分期定值纪律**：
  - **试单期缺省值**：沿用单笔 **`$25`** / 日累计 **`$250`**（`configs/clob_gateway.yaml` 缺省；试单授权执行时按 [`试单运行手册草案`](P8-S305B-TRIAL-RUNBOOK_试单运行手册草案_v0.1.md) 临时单向收紧为 `$6 / $15`；当前依常设指令 `STANDING-DIRECTIVE-NOREAL-ORDER` 保持 `PAPER` 冻结待触发）；
  - **常态运营值（`v1.1` 不拍美元数字）**：常态单笔闸/日闸随 **`S3-12 GATE-LIVE`** 按业主实际批准的活跃站数 $N$ 与总资金池 $P_{\text{tier}}$ 依上式计算并写入 `configs/clob_gateway.yaml`；任何调大须业主签字，调小可随时配合台账留痕执行。

## §6 仓位与执行（门限额制 · 当前决策 `2026-11-17`）

1. **总门限额公式**：
   $$G = B \times w(\tau) \times s(\text{edge})$$
   - **时间定天花板（$w$）**，**机会定开门幅度（$s$）**；
   - **时间只调门、不开门**；当 $\text{edge} < m$（下注门槛）时 $s(\text{edge}) \equiv 0$（`s(edge)` 中间过渡形状及黄灯半额乘法系数归 `D-6` / 后续账本细化）。
2. **`w(τ)` 仓位时间骨架（首期选择 `2026-11-17`）**：
   - 选定 **`B2` 锚底幂函数**：
     $$w(\tau) = w_0 + (1 - w_0)\left(1 - \frac{\tau}{\tau_{\max}}\right)^p, \qquad \tau \in [0, \tau_{\max}]$$
   - **`w₀`（不取裸常数）**：严格由推导式确定并登记账本依据字段：
     $$w_0 = \max\!\left(\frac{\text{有效最小单折算}}{B},\; \text{前置消化意图值}\right)$$
   - **`p`（曲率指数）**：当前占位 **`p = 1.5`**（凸形，数据前预设；*月度复检重估；数据充分时形态本身可让位于经验曲线*）。
3. **执行手法 `φ`（首期选择 `2026-11-17`）**：
   - 选定 **Edge 感知参与率（Edge-Aware POV）**：
     $$\text{单轮目标量} = \min\!\Big(\text{差额 } D,\; \sum_{j \in \mathcal{J}_{\text{qual}}(m)} \rho(\text{edge}_j) \cdot \text{size}_j\Big)$$
     - **合格深度 $\mathcal{J}_{\text{qual}}(m)$**：沿当前可见卖盘（`AskBook`）从优到劣遍历，逐档含费边际 $\text{edge}_j \ge m$ 的累计可用深度（**价格侧复用门槛 `m`，零新增价格参数**；对齐现役 [`penetration_probe.py`](../../src/pricing/penetration_probe.py) 之费用口径核验前提，`src/pricing/` 锁定文件零修改）；
     - **参与率函数**：$\rho(\text{edge}) = \text{clip}\big(\rho_0 + k(\text{edge} - m),\; \rho_{\min},\; \rho_{\max}\big)$；**当前占位 `k = 0`**（首期选择以固定 POV 安全起步，保留一次成型接口，待实盘/假盘校准数据到位后于月度复检考虑开启 $k > 0$）；
     - **自然止损与订单类型**：逐档吃深至边际 $\text{edge}_j < m$ 即自动停手；全部采用**限价 IOC 单（CLOB 映射 `FAK`）**，**严禁市价单**。
4. **超门条款**：当 `G` 因 `edge` 缩水落到当前持仓之下时，**不自动减仓、不加仓**（当前决策 `2026-11-17`）。
5. **主动退出 / 减仓规则**：**`v1` 不做**，完整理由与重开条件登记于 [`§9`](#9-可选改进项登记下一版本候选池)。
6. **废止条款（`2026-11-17` 用户裁决）**：
   - **废止旧“加仓原因区分”条款（原拟：模型更新致 `edge` 扩大可加 / 仅价格漂移不加）**。
   - **废止理由**：在门限额制（$G = B \times w(\tau) \times s(\text{edge})$）下，价格向有利方向漂移造成的 `edge` 扩大自然抬高门限额 $G$ 从而开门产生正差额 $D$；区分“模型动还是盘口动”与“只按当前边际机会大小配置上限”的核心逻辑直接冲突。
   - *仓库核查记录*：`2026-11-17` 全仓检索 `docs/` 确认现存活跃文档未残留该旧条款条文；特于此正式记录废止裁决，严禁后续文档或 `T4/T8` 实现回引。
7. **背景注记（门限额制 vs 目标额制）**：门限额制取代了讨论中被否决的目标额制（否决理由：投多少应由机会好坏决定，时间流逝本身不应制造买入信号）；完整决策过程见 [`P8-EXECUTION-DESIGN v1.0`](P8-EXECUTION-DESIGN_w与phi设计与决策记录_v1.0.md)。
