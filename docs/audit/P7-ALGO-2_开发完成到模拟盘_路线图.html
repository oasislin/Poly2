依据：规格书 v0.6 §9 验证与验收（F-2 锁）、§7 参数挂锁表、算法描述 §10 ECE 梯级门禁、未定项清单第二/三层。示意结构，非精确比例。
阶段 0 · 当前
按 v0.6 文档开发完成
代码可完备编写（M-8）；运行命令与参数落地 [F-2 LOCKED]
现在即可 · 跑得通
链路冒烟 / 录播回放
单测·契约测试·S1→S7 空跑·无 NaN·Fail-Closed 不误触发·S6 只读观测·结算复刻

卡点① · 硬前置
F-2 绿灯闸门
概率层 ECE/CRPSS 门禁：RED（熔断）/ YELLOW（带旗禁投）/ GREEN（解锁标定）
未绿灯 → 凯利标定与一切 sizing 调优不得开工
卡点② · 解锁后
两步标定
Step 0 概率门禁审计 → Step 1 反事实 sizing 产出 (θ,η,δμ,δσ) → Step 2 复核 fractional_multiplier；min_edge / z_crit / z_cert / max_rehedge_loss 标定
参数挂锁全部解锁后才能落地运行
阶段 2 · 目标
正式模拟盘
纸面盘链路运行（F-2 绿灯后）+ 2019 盲测年 Airgap 回测验证通道 → 行为验收
此时才验证"跑得好"
开发完成后 → 模拟盘前，需要增加的工作
① 概率层 F-2 绿灯（最大前置，独立于本规格）
EMOS 概率模型训练与评估；Binding ECE ≤ 0.05 ∧ 交易窗口 ECE ≤ 0.0100 → GREEN。P1 原则：本规格只消费、不修正概率输出——概率层工作属另一条任务线，必须先绿灯。
② 数据资产就绪与真实冒烟
2019 盲测年历史数据、GEFS reforecast 采集确认（铁律：不得预设不存在的资产）；Data API v2 / gamma 元数据 / 盘口深度真实契约测试；tick/lot 真实实例值实测回填（开放项 4）。
③ 标定流水线与纸面盘细节落地
两步标定 Step 1/2 全流程；[待标定] 项（min_edge / z_crit / z_cert / max_rehedge_loss）标定；paper_engine / settlement_sim 模拟循环细节（快照频率、成交撮合规则、结算判定时序——规格书第三层留白）；JSU/EVT 闭式灵敏度公式（若用非高斯族）。
结论：开发完成当天即可跑"链路冒烟/录播回放"（验证跑得通），但正式模拟盘（验证跑得好）被 F-2 绿灯硬前置 + 参数挂锁 + 数据资产三件事卡住；缺一不可，顺序为：概率层 GREEN → 数据资产确认 → 两步标定解锁 → 正式模拟盘。
