# ADR-0007：数据源重铸与站点宇宙扩展（M0' / Round 5 综合裁决）

- **状态**：Accepted
- **日期**：2026-09-04
- **裁决人**：项目负责人
- **影响范围**：项目方案（v2.4.1 → v2.5）、Phase 1 产出参数、Phase 2 前置条件

## 1. 背景

M0'（结算站点身份审计）与 Round 5（NWS WRH 精度裁决）两项子任务完成后，
产生四项推翻级发现，动摇了 Phase 1 的两大前提（Wunderground 数据底座、
{ZSPD, KDEN} 站点宇宙）：

1. **WU 真值失效**：Wunderground 历史日表相对 ASOS 原生报文存在
   -2.0°F ~ -5.1°F 系统性负偏差（n=3 实证，provisional N(-2.8, 1.5²)），
   不能再作为训练真值与气候学 Floor 口径；
2. **探针精度缺陷**：Synoptic API 整数摄氏度回退产生 ±0.5°F 级伪影，
   已确认污染 ≥4 个历史数值（Chicago 04-12、NYC 09-01、Miami ×2）；
   修复（RMK T 组 0.1°C 正则解析）已合入 NwsWrhAdapter；
3. **结算站裁决**：Denver 结算站为 KBKF（4/4 判例），KDEN 无对应市场；
   Chicago=KORD、NYC=KLGA 等共 10 站锁定；
4. **站点宇宙重构**：ZSPD 一票否决（无日盘 + 非 NWS），EGLC 否决，
   美国站池 12 站（含 KAUS 扩充候选、KDCA 观察）成为唯一主管线。

Phase 1 的结论层资产（算法、三层预测栈、验收引擎）不受影响——它们全部
由 IEM 原报级证据支撑；受影响的是数据本体与训练参数。

## 2. 决定

| # | 决定 |
|---|---|
| D1 | 校准真值唯一源 = IEM ASOS METAR 原报，温度值强制从 RMK T 组提取（0.1°C 精度） |
| D2 | 结算真值源 = NWS WRH 时序表（Era 2 法定源）；WU 降为三级降级源；历史数据消费须先查 Market Vintage 标签，Era 1 段仅作压测 |
| D3 | 站点宇宙 = 美国 12 站池（六要素门禁准入），首发 KORD；ZSPD 转观测档案 |
| D4 | 插入 Phase 1.5（数据管道重建与校准语料库），旧 WU 数据底座与 Phase 1 的 40 组参数作废重训 |
| D5 | 旧 σ_clim Floor（WU 口径）判定作废，以 IEM 原报 2000-2018 重建 |

## 3. 否决的备选方案

- **仅修补数据、不重取**：被否——探针污染不可逐值排查，训练语料必须
  100% 出自修复后管线，结构上杜绝"漏网污染字节"；
- **封存全部 Phase 1 代码从零重写**：被否——算法与三层栈经代码核验闭环
  （v2.4.1 §6），推翻成本零收益，采用"剥离重构"路径。

## 4. 后果

**正面**：证据链精度提升至原报级；站池从 2 站扩展至 12 站（模型矩阵
240 组）；数据质量门禁制度化，杜绝同类污染复发。

**负面 / 代价**：
- Phase 1 全部模型参数作废重训（Phase 1.5 约 10~13 人天）；
- Phase 2 执行文件 v1.3 的三项条款与新裁决冲突，开工前须另行裁决
  （结算真值源 / 切换窗 0.75h 阈值语义 / 08-31 特报语义）——
  见项目方案 v2.5 §8.1 待开 ADR 条目。
