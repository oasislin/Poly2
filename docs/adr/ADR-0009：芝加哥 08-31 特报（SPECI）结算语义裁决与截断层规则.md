# ADR-0009：芝加哥 08-31 特报（SPECI）结算语义裁决与截断层规则

- **状态**：Accepted
- **日期**：2026-09-11
- **裁决人**：量化工程团队
- **影响范围**：Phase 1.5 Task 03（PENDING-08 清账）、Task 06（整点与高频切片）、Phase 2（结算复刻器与交易截断层）

---

## 1. 背景与事实穿透 (Context & Empirical Evidence)

在对首发主战站芝加哥（`KORD`）的连续 7 日已结算盘口（2026-08-27 至 2026-09-02）审计中，发现 **2026-08-31** 的结算表现出与标准整点报（Hourly METAR）的偏离：

1. **盘口结算结果**：Polymarket 官方 `highest-temperature-in-chicago-on-august-31-2026` 市场的获胜区间为 **`86-87°F`**。
2. **KORD 整点报文（Hourly `:51`）观测序列**：
   - 12:51 CDT: 82.0°F
   - 13:51 CDT: 84.0°F
   - 14:51 CDT: 84.0°F
   - 15:51 CDT: 84.0°F
   - 16:51 CDT: **85.0°F**（当日整点最高温）
   - 若仅采信整点报，当日最高温为 85.0°F，获胜区间应为 `84-85°F`。
3. **关键离散特报（SPECI）确证**：
   - 当日下午芝加哥奥黑尔机场遭遇雷暴天气（METAR 附注包含 `TSB38` 雷暴开始标记）；
   - 在 **13:44 CDT**（18:44 UTC），ASOS 自动发报系统发布了一条紧急特报（SPECI）：
     ```text
     SPECI KORD 311844Z 24015G25KT 10SM TSRA BKN045CB 30/21 A2988 RMK AO2 TSB38 T03000211
     ```
     其中干球温度为 30.0°C，`RMK T` 组明确记录 $T = +30.0^\circ\text{C} = \mathbf{86.0^\circ\text{F}}$！
4. **NWS WRH 官方展示行为实证**：
   - NWS WRH 的 "Show Hourly Data" 页面虽然标题含有 "Hourly"，但其实际渲染逻辑是展示官方时序表（Time Series Tabular），当气象台站发布 SPECI 时，WRH 会原生将特报插播进表格中展示；
   - Polymarket 预言机及人工审计在结算时读取的是该表格呈现的日内最高极值，因此直接采纳了 13:44 特报录得的 **86.0°F**，导致 `86-87°F` 结算胜出。

## 2. 裁决决定 (Decisions)

| # | 决策项 | 决策内容与工程约束 |
|---|---|---|
| **D1** | **特报法定结算效力** | **Polymarket 在 Era 2 下的结算采信包含特报（SPECI）在内的所有官方公布观测值**。不可将 "Show Hourly Data" 狭隘理解为硬过滤排除 SPECI，必须认定特报具有完全合法的结算效力。 |
| **D2** | **IEM 管道默认保留全量发报** | Task 02 开发的 `iem_adapter` 及后续 Task 04 全量重取中，API 请求参数**必须维持 `report_type=["1", "2"]`**（即同时拉取 Routine METAR 与 Special SPECI），绝不可丢弃特报报文。 |
| **D3** | **数据切片与特征库双轨支持 (Task 06)** | 下游 Task 06 特征库生成时，保持双轨字段：<br>① `tmax_daily_all_reports`（包含 SPECI 极值，作为基准结算真值）；<br>② `tmax_daily_hourly_only`（仅 `:50-:55` 窗口整点报，作为稳健特征与抗噪对照）。 |
| **D4** | **挂账 PENDING-08 正式关闭** | 芝加哥 08-31 结算机制完全破译闭环，语义无任何游离或模糊，状态正式翻转为 **`status: RESOLVED`**。 |

## 3. 后果与影响 (Consequences)

### 正面影响
- 彻底消除了 Phase 1 遗留的特报语义争议，避免了在 Phase 2 结算复刻器中误设“强制剔除特报”的逻辑导致回测与实盘结算产生系统性错位；
- 明确了雷暴、阵风锋过境等急剧对流天气下短暂温度尖峰（如 13:44 升温）的结算地位，提升了极端天气条件下的定价鲁棒性。

### 潜在风险与对策
- **特报不可预测性**：SPECI 采样时间非等间隔，中尺度预报模型（如 GEFS 3小时间隔）无法精确预测突发特报的温度尖峰。
- **对策**：在二元期权临界边缘时，风控模型需针对具有强雷暴潜势（如 CAPE 极高）的交易日适当放大方差膨胀系数 $\sigma_{\text{speci}}$，防止在区间边缘重仓过度拟合。
