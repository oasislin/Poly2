### 2.1 KLAX 春季 $c_{\text{train}} = 1.2345$ 顺子值确定性多起点复核

针对 $c_{\text{train}}$ 极值点 KLAX 春季展示出四位连续数字 `1.2345` 的疑问，专项抽检该气候单元（2000–2018 年春季 18h TMAX，有效样本量 $N=1748$），运行法定 5 初猜多起点优化器复算：
1. **收敛性**: 5 组独立初猜全部 100% 收敛至同一全局最小 CRPS 目标函数值 `2.07989547`，解向量无二义性：
   - 胜出最优参数：$a = 20.98964262, b = 0.72078318, c = 3.15122140, d = 0.55911797$
2. **残差与方差解析分解**:
   - 经 30 天因果偏差校准后的观测残差方差 $\text{Var}(\text{resid}_{\text{calib}}) = 15.3024678004$
   - 对应均方原始预报不确定度 $\mathbb{E}[\sigma_{\text{raw}}^2] = 10.0408277512$
   - 两者真实方差比率 $\text{Ratio} = \frac{15.3024678004}{10.0408277512} = 1.5240245306$
   - 开方得到精确值：$c_{\text{train}} = \sqrt{1.5240245306} = \mathbf{1.2345138843318002}$
3. **结论**: 四位小数呈现 `1.2345` 顺子值纯属数值代数巧合，系底层样本残差与全局极小参数计算之客观物理结果，非人工截断或优化器默认初猜。

### 2.2 夏季 $c_{\text{train}}$ 偏低结构的季节与天气学物理机理注记

在 40 组站×季 $c_{\text{train}}$ 矩阵中，呈现出全站一致的夏季偏低特征：
- **四季横向对比**: 冬季均值 $1.0798$、春季均值 $1.1026$、秋季均值 $1.0944$，而**夏季均值仅 $1.0304$**。
- **跌破 1.0 的站点**: KAUS ($0.9693$)、KATL ($0.9748$)、KSEA ($0.9812$)、KLAX ($0.9950$) 夏季 $c_{\text{train}} < 1.0$。
- **物理成因**:
  1. 夏季北美受副热带高压脊稳定控制，斜压性锋面活动微弱，日最高温的真实日际方差处于全年极小期；
  2. GEFS 集合预报在夏季的原始发散度（主要由积云对流参数化扰动产生）相对充足，未出现中高纬冬春季因强斜压波动力低估发散度的现象；
  3. 部分台站原始预报方差甚至略大于真实残差方差，导致校准因子 $c_{\text{train}} = \sqrt{\text{Var}(e) / \mathbb{E}[\sigma_{\text{raw}}^2]}$ 物理性地收敛在 $1.0$ 附近或微幅小于 $1.0$，具备坚实的天气动力学自洽性。
