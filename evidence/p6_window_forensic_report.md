## 二、样本量构成解剖：13,739 / 13,740 的数学实质

在各格的 `summary.json` 中，字段 `sample_size_days` 记录为 `13740` 或 `13739`。本审计彻底解剖其计算来源与构成：

### 2.1 来源代码提取
在 `scripts/run_p6_fullgrid_tmax.py` 第 114–182 行：
```python
def harvest_cell_daily_records(...):
    daily_records = []
    for r in range(20):
        pred_path = target_dir / f"cv_fold_{r}_predictions.parquet"
        df_fold = pd.read_parquet(pred_path)
        df_fold_daily = df_fold.drop_duplicates(subset=["target_date"]).sort_values("target_date").reset_index(drop=True)
        for _, row in df_fold_daily.iterrows():
            entry = { "sample_id": len(daily_records), "fold_id": r, "target_date": str(row["target_date"]), ... }
            daily_records.append(entry)
    df_days = pd.DataFrame(daily_records)
    return df_days, hasher.hexdigest()
```
并在 `audit_grid_cell_reliability` 中统计：
`n_days = len(df_full_days)`，并将此 `n_days` 存入 `summary.json` 的 `sample_size_days` 字段。

### 2.2 构成拆解：折·日总和 vs 独立日历日
1. **真实物理含义**：
   `sample_size_days` 的实质是 **20 个验证块的折·日总和（Total Fold-Days in Validation Blocks）**，并非唯一的独立日历日数。
2. **20 折评估块天数列表（以 KMIA 18h / KORD 18h 为例）**：
   - Fold 0 ~ 6: 每折 690 天
   - Fold 7: 670 天
   - Fold 8 ~ 10: 每折 690 天
   - Fold 11: 670 天
   - Fold 12 ~ 14: 每折 690 天
   - Fold 15: 670 天
   - Fold 16 ~ 19: 每折 690 天
   - **折·日总和**：$17 \times 690 + 3 \times 670 = 11,730 + 2,010 = \mathbf{13,740\ \text{折·日}}$
3. **独立日历日构成**：
   - 2000–2018 年共 19 年，总日历日为 $19 \times 365 + 5 = 6,940$ 天；
   - 在 20 折 Block-CV 中，每折独立抽取 10% 块留出作为验证集（存在重叠采样）；
   - 20 折验证集并集覆盖的**唯一日历日（Unique Calendar Days）**为 **`5,860 天`**（占全历史样本的 84.4%）；
   - 平均每个日历日在 20 折验证中被评估 $13,740 / 5,860 \approx 2.34$ 次。

### 2.3 为何 24h 以后变为 13,739？
- 12h 与 18h 的时效在预测初始化当日（Day 0），首个样本自 2000-01-01 开始，有效日 6,940 天，验证总折·日为 13,740；
- 24h~42h 的预报时效跨入 Day 1，首个有效预报日自 2000-01-02 开始（2000-01-01 因缺乏前序 24h 预报不可用），总有效日变为 6,938 天；Fold 4 的验证块天数从 690 变为 689，因此总折·日为 **`13,739`**；
- 48h~66h 跨入 Day 2（首日为 2000-01-03），总折·日为 **`13,738`**；
- 72h~78h 跨入 Day 3（首日为 2000-01-04），总折·日为 **`13,737`**。

## 五、法医定级与处置分支判定

- **事件定级**：**良性（折·日措辞歧义，零代码污染，零窗口越界）**
- **法医证据**：
  1. 2019 年盲测数据**零加载、零泄露、零污染**，Airgap 坚不可摧；

- **处置动作**：
