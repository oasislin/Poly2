## 三、综合归因结论

1. **排除尺度异方差未吸收假象**：42h 与 66h 的 $\sigma_{\text{eff}}$ 方差比均为 `1.0026~1.0027`，Q1~Q4 全落入 $[0.85, 1.15]$，彻底排除尺度误标。
2. **否定“单纯锋面时机主导”假说**：平静日子集峰度均值（`1.56~1.94`）系统性高于锋面日（`0.83~0.90`），证实将厚尾单一归因为“锋面转换时机误差”在数理上不成立。
3. **确诊为稀疏极端事件扰动**：留一法敏感度测试表明，每折 6,248 天中仅需剔除 $3\sim 5$ 天（约 $0.05\%\sim 0.08\%$），超额峰度即全面跌破 $1.0$。这表明 42h 与 66h 的超额峰度主要由**年均不到 1 天的孤立极端预报偏差事件**所支配（如极端阻塞高压脊或反常突发极涡）。
4. **验证了 BIC 选型机制的稳健鲁棒性**：在 42h，4 折因极端残差较大达到 $\Delta\text{BIC} < -10$ 而受控激活 EVT 防线，16 折保持高斯；在 66h，由于极端点更为稀疏（剔除 3 天即降至 0.98），20 折全部未达 $\Delta\text{BIC} < -10$，模型库 100% 稳健回退高斯基准。
