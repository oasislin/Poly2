## 二、历史三处实质数字冲突逐项深度对账与根因定位

在 Round 2 交付中，评审委员会独立复算发现探针文件与结算报告存在三处实质数字差异。经底层代码逐行追溯，差异根因系**开发探索期“粗调探针状态（State A）”与“结算脚本状态（State B）”的参数与代码脱节**所致，具体对账如下：

### 2.1 冲突项对照总表

| 统计指标 | 站点 | 切靶预算表 (探针状态 A) | 历史结算报告 (Case-B 状态 B) | 新版法定重算 (冻结 $c_{\text{train}}$ 状态 C) | 冲突根因与管线状态差异 |
| :--- | :---: | :---: | :---: | :---: | :--- |
| **K-S 检验 $p$-val** | KMIA | **0.1003** | **0.0172** | **0.0351** | 探针脚本采用统一固定 $\text{factor}=1.15$ 与 `window=40`；历史结算采用 2019 同窗 $\text{var\_factor}=1.2035$ 与 `window=30`；新版采用历史冻结 $c_{\text{train}}=1.1090$ 与 `window=30`。 |

### 2.2 冲突根因代码行定位与状态说明

#### 1. 探针状态 A (`r2_target_switch_budget.csv`)
- **运行脚本**: 临时探针原型 `scratch/probe_budget.py`
- **参数配置**:
  - 因果滑动窗口: `window = 40` 天
  - 方差膨胀系数: 固定无差别 `factor = 1.15`
- **产生问题**: 该脚本仅用于测算 GHCN 切靶消解了多少原始偏差，其推演列被误加上 `final_` 前缀并入库，造成与主结算报告混淆。

#### 2. 历史结算状态 B (历史 `recompute_settlement_report.md`)
- **运行脚本**: `scripts/audit_provenance_and_recompute.py` (Commit `c3ca0bd`)
- **参数配置**:
  - 因果滑动窗口: `window = 30` 天
  - 方差膨胀系数: 基于 2019 单年残差的同窗构造值（KMIA $c = 1.2035$, KSFO $c = 1.1588$）
- **定性承认**: 严格认领为 **Case-B 前瞻泄漏参数**，属于不合规状态。

#### 3. 现行唯一法定状态 C (最新 `recompute_settlement_report.md`)
- **依据指令**: 《修复轮指令 v3》D-1、D-6 条款
- **参数配置**:
  - 因果滑动窗口: `window = 30` 天（**纯由 2000–2018 训练窗选定**，见第三节）
  - 方差膨胀系数: 严格由 2000–2018 训练窗残差方差拟合并冻结的 $c_{\text{train}}$（KORD $1.0678$, KMIA $1.1090$, KSFO $1.0664$）
- **法定结论**: 状态 B 全面作废，**状态 C 正式取代历史状态成为唯一法定结算值**。

## 三、关键参数外生性与训练窗选定声明 (授权条件 ① 落地)

### 3.1 Case-B 泄漏参数取代声明
工程组正式记录在案：
> 现行历史法定结算表中使用的 KMIA $c=1.2035$ 及三站 $s\equiv 1.000000$ 系基于 Case-B 2019 OOS 残差同窗计算的泄漏参数。本次重算已**完全由 2000–2018 训练窗冻结的 $c_{\text{train}}$（KORD 1.0678, KMIA 1.1090, KSFO 1.0664）全面取代**，消除了任何前瞻构造恒等式，OOS 实测方差比归正为真实客观统计量 $s_{\text{oos}}$。

### 3.2 `window = 30` 仅由训练窗选定的书面证明
依据工件 [`evidence/training_variance_factors.json`](training_variance_factors.json)，工程组在 2000–2018 训练窗口（6,940 站·日）对因果滑动窗口长度 $W \in \{10, 20, 30, 45, 60\}$ 进行了严格离线交叉检验，实测 MAE 如下：

| 候选窗口长度 $W$ | KORD 训练集 MAE | KMIA 训练集 MAE | KSFO 训练集 MAE | 三站平均训练 MAE |
| :---: | :---: | :---: | :---: | :---: |
| $W = 10$ 天 | $2.5587^\circ\text{F}$ | $1.2899^\circ\text{F}$ | $3.0997^\circ\text{F}$ | $2.3161^\circ\text{F}$ |
| $W = 20$ 天 | $2.5269^\circ\text{F}$ | $1.2797^\circ\text{F}$ | $3.0576^\circ\text{F}$ | $2.2881^\circ\text{F}$ |
| **$W = 30$ 天** | **$2.5242^\circ\text{F}$** | **$1.2796^\circ\text{F}$** | **$3.0556^\circ\text{F}$** | **$2.2865^\circ\text{F}$** (最优) |
| $W = 45$ 天 | $2.5242^\circ\text{F}$ | $1.2780^\circ\text{F}$ | $3.0592^\circ\text{F}$ | $2.2871^\circ\text{F}$ |
| $W = 60$ 天 | $2.5249^\circ\text{F}$ | $1.2817^\circ\text{F}$ | $3.0611^\circ\text{F}$ | $2.2892^\circ\text{F}$ |

**结论**：在 2000–2018 训练集中，$W=30$ 天在三站平均 MAE 上取得全局最优值（$2.2865^\circ\text{F}$），并在 KORD 与 KSFO 单站均取得最优 MAE。**该参数完全确立于 2019 年之前的历史数据，无任何 2019 样本外信息引入**。
