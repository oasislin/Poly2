## 一、 变更背景与原因

现存 `data/contracts/physical_param_contract.json` 中的 `s_oos`（离散度方差比，Out-of-Sample Variance Ratio）字段历史取值实测为 **2019 盲测全年样本内计算值**（如 `KORD_36h = 0.833009`、`KMIA_30h = 1.363831`）。

若直接将 2019 样本内估计的 $s_{\text{oos}}$ 带入后续 2019 盲测回放检验 C（$D+0$ 条件定价可靠性检验）中，将导致检验 C 的评判尺子消费了被检验年度自身的二阶矩先验，构成**二阶矩先验泄漏**，破坏检验 C 作为独立外层判官的合法性。

经业主裁定选定方案 a：
1. **解冻契约 $s_{\text{oos}}$ 段**，全面采用 **2000–2018 二十折 Block-CV 折外（OOF）残差**进行重推，**严禁任何 2019 数据参与**；
2. **契约版本化入库**：新推 $s_{\text{oos}}$ 写入法定消费字段，原 2019 样本内旧值全 22 格**严禁删除**，转入 `s_oos_historical` 字段并显式标注：**`"样本内估计，仅诊断参考，禁止入检验 C"`**；
3. 保障向下兼容与 Schema 校验，确保消费链单测全绿。

## 二、 2000–2018 二十折 Block-CV OOF 估计口径与公式

### 1. 数据来源与样本池
- **台站与时效**：覆盖 KORD（芝加哥）与 KMIA（迈阿密）TMax 12h~72h 全部 22 个法定网格单元（排除 6h 与 78h）。
- **验证折外数据**：直接自冻结的 20 折 Block-CV 验证工件提取：
  - `KORD_18h`：`evidence/cv_fold_{0..19}_predictions.parquet`
  - 其余 21 格：`evidence/fullgrid_tmax/cells/{station}_{lead_hours}h/cv_fold_{0..19}_predictions.parquet`
- **样本量**：每格包含 20 折累计 13,737 ~ 13,740 条折外日预报记录（覆盖 5,857 ~ 5,860 个独立日真值）。

### 2. 数学公式与计算口径
- 折外单日残差：
  $$e_i = y_i - \mu_i$$
  其中 $y_i$ 为实测 TMax（°F），$\mu_i$ 为 fold-local 拟合的 EMOS 均值预报 $\mu_i = a + b \cdot \text{ens\_mean}_i$。
- 折外残差样本方差：
  $$\text{Var}(e) = \frac{1}{N - 1} \sum_{i=1}^N (e_i - \bar{e})^2 \quad (\text{ddof} = 1)$$
- 期望有效预报方差：
  $$\mathbb{E}[\sigma_{\text{eff}}^2] = \frac{1}{N} \sum_{i=1}^N \sigma_i^2$$
  其中 $\sigma_i = \max(0.90, \sigma_{\text{raw}, i} \cdot c_{\text{train}})$，均为折内训练样本所估计。
- 法定方差比估计量：
  $$s_{\text{oos}}^{\text{CV}} = \frac{\text{Var}(e)}{\mathbb{E}[\sigma_{\text{eff}}^2]}$$
- 法定方差膨胀乘数：
  $$c \equiv \frac{\sigma_{\text{adj}}}{\sigma_{\text{eff}}} = \sqrt{\max(1.0, s_{\text{oos}}^{\text{CV}})}$$
